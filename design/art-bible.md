**视觉身份 · 视觉锚点 · 资产规格**
文责：美术总监 林绘澄 ｜ Task AD-001 ｜ P0 ｜ solo 评审

## 0. 结论先行

> 一句话定位：**一台「夜场对质台」——玩家与 NPC 左右对峙，用双向「我有异议！」的闪帧与大字作为整局的情绪心跳。**

关键判断：

1. **视觉铁三角**：深邃靛蓝（理性对质底色）+ 异议红（冲突/反击）+ 认同金（正向/胜利）。全游戏不许出现第四种「情绪主色」。
2. **立绘工艺**：赛璐璐厚涂 + 强描边 + 高对比轮廓光；立绘用分层 PNG/WebP，HUD 用 SVG/CSS 动画。
3. **玩家换装 = 分层不捏脸**：3 套预设 + 4 部位分层（发型/发色/服装/配饰，各 3~4 档），14 部件覆盖 100+ 组合。
4. **15 个 NPC = 5 层 × 3**，半身立绘，每 NPC 核心 4 表情（默认/动摇/得意/被说服）+ 1 愿景（警觉）。
5. **演出双向**：玩家命中薄弱点→玩家金闪「异议」、NPC 动摇；玩家命中强项→NPC 红闪「异议」反击、玩家被反将。两边同一套语法、配色互换。
6. **可访问性定级 Standard**（demo 基线）。
7. **资产优先级分「demo 必需 / 愿景」两档**。

## 1. 视觉身份九节

### 1.1 名字
**「言刃 · 对峙法庭」**（内部代号 `VISION-BB`）——「语言如刀锋交锋」。

### 1.2 一句话定位
深夜里一场一对一的语言决斗，每一次「异议」都是一记挥出的刀刃。

### 1.3 调性关键词（5 词，写进所有资产 brief）
**对峙 · 锋利 · 心跳 · 裁决 · 爽快**

### 1.4 色彩主基调
深邃靛蓝为底（冷静的「夜场对质」），异议红为冲突心跳，认同金为胜利曙光。完整色板见 §6。

### 1.5 字体方向
- 大字异议/标题：思源宋体 Heavy（Noto Serif SC Black）——庄重、判决书感。
- UI/正文/对话：思源黑体（Noto Sans SC）。
- 数字/token 倒计时：思源黑体 Bold + 等宽数字（tabular-nums），或 JetBrains Mono（OFL）。
- 全部开源可商用（SIL OFL 1.1），零字体授权风险，天然规避 Capcom 字体。

### 1.6 质感
「赛璐璐厚涂 + 强描边」2D 立绘，叠 2~4% 不透明度的判决书/票据纸张纹理；UI 用「印章/划线/票据裁切」质感，避免拟真 3D 与扁平塑料感。

### 1.7 光影
顶部主光 + 双侧对立轮廓光：玩家侧冷青描边、NPC 侧暖橙/品红描边，制造「两人被同一束顶光审判」的张力。

### 1.8 禁忌（硬约束）
- ❌ 不使用/不仿制逆转裁判角色、Capcom 字体、法庭场景原画。
- ❌ 不复刻 Capcom 红底白字异议排版克隆。
- ❌ 不允许第三种「情绪主色」之外的杂色抢戏。
- ❌ 禁止血腥、低俗、恐怖惊悚（赛事合规）。
- ❌ 禁止字体瘦弱无气势、低对比灰字（可访问性）。

|---|---|---|

## 2. 视觉锚点：对立式立绘布局

### 2.1 画面分区（16:9 基准）

```
┌────────────────────────────────────────────────────────┐
│  顶栏：回合/议题标题 · token 倒计时(右上) · 难度(左上)     │
├────────────────────────────────────────────────────────┤
│  ┌──────────┐         ┌──────────┐         ┌─────────┐ │
│  │          │  ①大字异议  │          │ 六维    │ │
│  │ 玩家立绘  │  (中央闪帧)  │ NPC立绘   │ 雷达图  │ │
│  │(左·面向右)│         │(右·面向左)│ 认同度条 │ │
│  │  占40%   │  ②中轴焦点区 │  占40%   │(中央HUD) │ │
│  └──────────┘         └──────────┘         └─────────┘ │
├────────────────────────────────────────────────────────┤
│  底部：对话框(气泡) + 打字机文字 · 选项/进攻角度按钮         │
└────────────────────────────────────────────────────────┘
```

- 玩家左、NPC 右，各占约 40%；中央 20% 为焦点区（六维雷达 + 认同度条 + 大字异议）。
- 玩家面向右、NPC 面向左，视线中轴交汇制造对视压力。
- 响应式降级：桌面 16:9 为主；竖屏改「上下对质」（愿景）。demo 仅做 16:9。

### 2.2 法庭对峙感的视觉语言（4 原则）

1. 对称但不相同（玩家冷青 vs NPC 暖橙）。
2. 留白即压力（焦点区只在异议/认同变化瞬间被打破）。
3. 视线即冲突（头部角度、眼珠严格朝对侧，不能看镜头）。
4. 裁决感靠 HUD 语法（认同条=判决刻度、token=倒计时票据、雷达=对质记录）。

## 3. 角色资产规格

### 3.1 玩家角色：预设形象 + 有限换装（分层，绝不捏脸）

| 层级 | 字段 | 建议档数 | demo 必需 |
|---|---|---|---|
| base | 身体/脸/基础 pose | 1 套 | ✅ |
| 发型 | 发型 | 4 档（短/中/长/束发） | 2 档 |
| 发色 | 配色 | 4 档（黑/棕/银/挑染） | 2 档 |
| 服装 | 服装 | 3 档（正装/休闲/学院） | 2 档 |
| 配饰 | 配饰 | 3 档（眼镜/耳饰/徽章） | 1 档 |

- 预设 3 套：①「青锋」理性 ②「赤刃」热忱 ③「玄墨」沉稳。demo 必做 1 套默认。
- 分层价值：4×4×3×3 = 144 组合，只需 14 个部件。
- 实现：Web 用 div/img 叠层（base→hair→outfit→accessory），不做捏脸网格。

### 3.2 NPC 立绘：15 个（5 层 × 3）

| 层 | 主题 | NPC 示例 | 视觉气质 |
|---|---|---|---|
| L1 | 生活层 | 街头大妈/邻里大爷/摊主 | 市井、随性、接地气 |
| L2 | 职场层 | 同事/领导/客户 | 克制、西装、压迫感 |
| L3 | 网络层 | 键盘侠/主播/意见领袖 | 张扬、色彩饱和、标签感 |
| L4 | 专业层 | 律师/教授/医生 | 权威、理性、制服/正装 |
| L5 | 大师层 | 国辩选手/哲学家/顶级主持人 | 气场最强、标志性轮廓 |

**单 NPC 立绘规格**：

| 项 | 规格 |
|---|---|
| 构图 | 半身立绘（demo 必需）；全身为愿景 |
| 基准分辨率 | 1536×2048（3:4 半身 @2x）；源 2048×2048 |
| 表情层级 | 默认/动摇/得意/被说服（4 核心）+ 警觉（1 愿景） |
| 导出格式 | WebP(q80) + PNG 回退；表情共用身体只换脸/嘴/眉图层 |
| 体积预算 | 单立绘(含 4 表情) ≤256KB WebP；单表情 ≤64KB |
| 命名 | `char_npc_{层}_{序号}_{state}.webp` |

### 3.3 角色表情状态机

**玩家侧（随 token 递减，400→140）**：

| 档位 | token 区间 | 状态 | 表情/动效 |
|---|---|---|---|
| ① | 400–300 | 从容 | 平静自信 |
| ② | 300–200 | 紧张 | 眉皱、眼神收束 |
| ③ | 200–140 | 焦虑 | 冒汗粒子、呼吸加快 |
| ④ | <140 | 绝望 | 面色发青、颤抖 |

> 状态切换 300ms 缓动，避免「啪一下变脸」塑料感。

**NPC 侧（随认同度 0→100% 与漂移触发）**：

| 表情 | 触发条件 | 语义 |
|---|---|---|
| 得意 | 认同度 <20%，或命中强项(认同度↓) | 占上风、反击前兆 |
| 警觉 | 认同度 20–50% | 正视玩家 |
| 动摇 | 认同度 50–80%，或命中薄弱点(+40/+20) | 被反将 |
| 被说服 | 认同度 ≥80% | 气势瓦解 |

> 对齐：命中薄弱点(+40/+20)→立即「动摇」+ 玩家「异议」；命中强项→「得意」+ NPC「异议」。+8 轻微命中只做「警觉」微表情，不触发整段异议，防演出泛滥。

## 4. 演出规格

### 4.1 「我有异议！」完整规格（双向对称）

| 项 | 玩家侧（认同度↑） | NPC 侧（认同度↓） |
|---|---|---|
| 大字文案 | 「我有异议！」 | 「异议！」/「胡扯！」 |
| 大字颜色 | 认同金 #F5C04E | 异议红 #FF3B4E |
| 全屏闪 | 金色闪帧 | 红色闪帧 |
| 放射线背景 | 金色放射线 | 红/紫放射线 |
| 屏幕震动 | 6–8px | 8–10px |
| 角色手势 | 前倾 + 伸手指出 | 前倾 + 拍桌/指斥 |
| 音效 | 「啪」冲击音 + 大喝 | 同左，音色更低沉 |
| 总时长 | 800–1200ms，可打断 | 同左 |

**节奏拆解（1000ms 标准异议）**：
1. 0–120ms：全屏闪。
2. 120–250ms：大字 + 放射线弹出（scale 0.6→1.0 overshoot）。
3. 250–600ms：屏幕震动 + 手势切 pose + 音效命中。
4. 600–1000ms：大字定格、余震衰减、淡出回正。

### 4.2 即时视觉反馈

| 触发 | 视觉反馈 |
|---|---|
| 认同度↑(+40/+20/+8) | 金色粒子 + 飘字 + 认同条脉冲 + 雷达轴高亮 + NPC 动摇 |
| 认同度↓ | 红/紫向下粒子 + 裂痕波纹 + NPC 得意反击 + 认同条变红 |
| token 递减 | 数字跳动/变红 + 玩家神情升级 + 屏幕边缘暗角渐进 |
| 六维漂移 | 雷达轴 300ms 平滑变形 + 命中轴发光 + 箭头 |

## 8. Web 沉浸感纪律（防「网页应用塑料感」清单）

1. 全屏即游戏：启动请求 Fullscreen，隐藏浏览器 chrome。
2. 无塑料 UI：禁系统默认按钮/输入框，全换游戏化控件。
3. 游戏化光标 + hover 反馈。
4. 音效三层分离（BGM/演出音/UI 音），可单独调节。
5. 动效纪律：requestAnimationFrame + CSS transform/opacity，粒子用 Canvas。
6. 性能预算：60fps；首屏资产 ≤3MB；惰性加载。
7. 开场 30 秒用演出教会「异议」节奏。
8. 紧张与爆发间保留 1 拍静默。
