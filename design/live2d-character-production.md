已落地：角色资源清单、立绘控制器、迟到资源隔离、表现参数驱动、独立验收台、状态/结算 BUG 修复，以及真实 Cubism Editor → MOC → 官方 Web Core 的制作链路。五层几何 proof 已完成呼吸、双眼开合和指向动作。本轮正式角色已经交付 1024×1536 的 13 层 PSD，含独立眼、眉、嘴、头发、衣身和角色左侧待机/伸指手臂，9 层默认可见、4 层隐藏；四张静态合成预览及独立 PSD 解码检查通过。

## 一套母模的最小交付

先完成一名玩家，不先批量扩展 NPC 或几十张换装图。最低证明材料为同一模型内：2 款发型 × 2 款面部 × 2 款服装，共 8 种组合；每种组合可运行四状态与同一异议动作。母模验收后扩展五名现有 NPC，最后扩展外观数量。

当前首套源稿固定为 1024×1536 透明画布，人物保留至腰下，前伸手势位于画布内；未来需要提高清晰度时再统一升级源稿。肩、肘、腕、颈、眼睛的锚点由实际源稿测量与编辑器绑定确认，不把旧文档任意填写的坐标当成已验收锚点。源画布与导出图集分辨率分别核对。

基础站姿让双肩完整、手臂轮廓可辨，便于拆层。抱臂、托腮和扶桌可作为独立动作姿态，分别处理遮挡与接触。第二版明确采用面向对手的 3/4 构图，为整条手臂向对手伸指预留横向空间，肩胸、头、眼和手指方向一致。大幅透视变化使用单独绘制的姿态分支。线条使用清晰粗细变化、平涂加块面阴影，避免写实厚涂、夸张大头、额外人物碎片和装饰背景。

建议分层命名（实际可在 Cubism 中细分）：

| 组 | 内容 |
|---|---|
| `Hair/A`、`Hair/B` | Back、SideL、SideR、Front、可摆动发束 |
| `Face/A`、`Face/B` | FaceBase、EarL/R、EyebrowL/R、EyeWhiteL/R、IrisL/R、UpperLidL/R、LowerLidL/R、MouthInside、UpperLip、LowerLip |
| `Body` | Neck、TorsoSkin、可见皮肤与衣服分离 |
| `Outfit/A`、`Outfit/B` | Torso、Collar、UpperSleeveL/R、ForeSleeveL/R、CuffL/R |
| `Arm/L`、`Arm/R` | UpperArm、Forearm、HandIdle；皮肤与衣袖关联但不合并 |
| `Objection` | HandPoint、ForearmPoint、SleevePoint、CuffPoint；待机/伸指互斥 |
| `Effects` | Sweat、可选压力阴影；与玩家可选外观分离 |

每层补全遮挡区：头发后的额头、脸后的耳、衣领后的颈、上臂后的躯干。层名不能替代实际拆层；只有合成图片的 PSD 不合格。

## 制模与动作

使用 Cubism Editor 建立 ArtMesh、遮罩、曲面/旋转变形器，绑定同一参数协议 `debate-humanoid-v1`。换装以多个 Parts 组成一个外观选项，身体和衣袖一起切换。各选项必须完成对应网格和关键形态；不能在运行时直接塞入任意 PNG 就共用变形。

呼吸和眨眼由独立参数层驱动，情绪决定脸部姿态与节律。原玩法压力顺序为从容 → 紧张 → 焦虑 → 绝望，数值阈值不变。现有驱动曲线只是测试默认值，必须在真实母模里校调。说话提示目前不是音频口型同步，正式口型要接实际音频幅度。

当前原创异议动作总长 1.5 秒：0–0.12 秒准备，0.12–0.20 秒切到前伸姿态，持有至 1.12 秒，1.12–1.20 秒收回，1.5 秒结束。嘴在 0.12–0.20 秒打开，0.8–1.12 秒关闭；动作全程接管 `ParamMouthOpenY`。换臂使用两次 80 毫秒交叉淡化和整体变形，端点待机臂/伸指臂互斥，中间仍会同时半透明，尚不是肩肘腕连续伸展的骨骼动作。
