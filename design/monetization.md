## 0. 结论先行（TL;DR）

- **一句话收费哲学**：本作收「想继续玩的钱」，不收「想赢的钱」。免费把压迫感送足（让玩家在 5 局内感受到"token 倒计时 + 读懂对手"的完整乐趣），付费解除"每日局数等待"、换外观与表达、解锁**审核过**的新命题与新对手——**绝不出售强度、资源、情报**。
- **三条红线**（卖了核心循环就崩，见 §1.2）：① 不卖"打得更赢"（判定/命中/难度/进度/胜率捷径）；② 不卖"说得更多"（游戏内 token/时间配额扩容）；③ 不卖"看得更透 / 生成对手"（六维数值攻略、付费深度复盘、运行时 AI 生成 NPC 能力）。
- **推荐方案（默认）＝免费增值**：免费玩家 **5 局/日**（3 局直接发放 + 2 局看激励视频兑换）；订阅 **15 元/月** = 无限对局（受 20 局/日反滥用上限）+ 全部外观 + 新内容提前玩。免费玩家**能打到 L5**，付费只影响重试频率、不影响进度上限与技能公平。
- **成本护栏 = 商业化底座**：对局 LLM 成本 ~0.03 元/局是"时长即成本"的物理约束。免费局数上限本身就是成本护栏；**必须在"可玩得爽"与"烧得起"之间取平衡，且把单局成本降到 0.02 是模型成立的前提，不是可选项**（目标渗透率下盈亏平衡线差约 7 个百分点）。
- 一次性买断（45~68 元）只作为**无订阅运营环境下的备选**（独立发行/买断制渠道），且必须配 20 局/日硬上限——因为"一次付费、永久开口"与"LLM 成本随开口线性增长"本质冲突，买断是成本结构上的劣势方案。

## 1. 收费哲学与红线

### 1.1 变现版 fun hypothesis

Fun hypothesis 原版：*在 token 预算的倒计时压迫下，读懂会漂移的六维人格，精准命中动态薄弱点。*

变现版（一句话）：

> **压迫感免费送，欲望才收费——玩家为"今天还想再打两局 / 想让对手更好看 / 想辩一道新题"付费，不为"想赢、想开挂、想开透视"付费。**

拆成三条"收什么"：
1. **收时间与频率**：解除每日局数等待（订阅 = 无限对局）。这对应玩家"差一点就赢、想立刻重打"的最高频冲动，也是成本护栏的安全阀（靠上限控成本）。
2. **收表达与身份**：立绘/音色/玩家形象/界面演出。纯外观、零强度、一次性资产，成本可控，且美术已有分层立绘与表情状态机基础（art-bible），量产路径通。
3. **收审核过的内容**：命题包、预设 NPC 包（gen_npcs 离线流水线产物经人工审核后包装出售）、赛季皮肤/赛事通行证。**只卖"成品内容"，不卖"生成能力"**（见 §2）。

### 1.2 三条不可越过的红线

> 判定标准：**任何付费点，若让"读人"变"背表"、让"活对手"变"沙袋"、让 token 变"无关痛痒的计数器"、让判定变"看谁钱多"，即构成支柱漂移，必须否决**（对齐总纲 §4.2 支柱漂移红线）。

| # | 红线（命名） | 绝对不卖的东西 | 为什么卖了核心循环就崩 |
|---|---|---|---|
| R1 | **不卖"打得更赢"** | 任何改变判定结果的付费：提高命中、降低 NPC 强度、自动提示正确答案、跳过未通关层、购买胜率/进度、付费"必胜局" | 天梯与复盘的"我变强了"价值瞬间归零；付费=作弊直接摧毁 P4（AI 是裁判，不是神谕）的可信度。付费最多改变"重试等待"，**永不改变"结果"** |
| R2 | **不卖"说得更多"** | 游戏内 token/时间配额的付费扩容：延长 token 卡、暂停卡、无限发言、加时 | token 稀缺是核心乐趣（P3 每一句话都是资源）；卖配额=有钱就能多说话，穷人一局富人三局。且**延长发言=单局 LLM 成本线性放大**（每回合 ~2 次调用），是设计上最贵、体验上最伤的双输项 |
| R3 | **不卖"看得更透 / 生成入口"** | ①六维数值/软肋点位的付费解锁或付费深度复盘（喂数值攻略）；②把"让玩家自定义生成新 NPC"当付费能力出售 | ①直接违反**复盘克制禁令**（systems-v2 §1）与总纲范围边界 #6，制造付费玩家 vs 免费玩家的情报差；②运行时 UGC 生成的内容安全与立场合规不可控（见 §2 对手生成讨论），gen_npcs 只应离线批量 + 人工审核后出售**成品** |

> 一句话记忆：**赢 / 说 / 看，三样都不卖。**

## 2. 付费点候选清单（brainstorm + 三维打分）

### 2.1 评分口径

| 维度 | 含义 | 评分方向 |
|---|---|---|
| **吸引力** | 对目标玩家（杠精型表达者/想练嘴皮子者）付费动机强弱 | 1=弱 … 5=强 |
| **破坏性** | 对四大支柱 / 复盘克制 / 公平的伤害程度 | 1=无害 … 5=伤根基 |
| **成本影响** | 对 LLM 成本 / 审核成本 / 资产成本的影响 | 1=无 … 5=高或不确定 |

**通过标准（建议）**：破坏性 ≤2 才允许进入付费设计；破坏性 3~4 需改造后再看（多数应砍掉）；破坏性 5 = 直接否决。

## 3. 推荐方案

### 3.1 默认方案 A：免费增值（免费局数 + 月订阅）——推荐

**结构**：

| 档位 | 每日对局 | 可玩内容 | 外观 | 广告 | 定价 |
|---|---|---|---|---|---|
| **免费玩家** | **5 局/日** = 3 直接发放 + 2 看激励视频兑换 | L1–L5 全部可达；50 基础命题全开放 | 默认立绘/默认音色/玩家 1 预设 | 失败结算页 + 每日加局（可跳过） | 0 |
| **订阅会员** | 不限（反滥用软上限 20 局/日） | 全部 + 新命题/NPC **提前 2 周玩** | 全部皮肤 / 音色 / 玩家形象 / 演出扩展 | 无 | **15 元/月**（年订阅 128，首月 6 元试玩） |
| **单品/单笔（订阅外补充）** | — | 单买命题包 3~6 元 / NPC 预设包 6~12 元 | 单件皮肤 6 元 / 主题礼包 12 元 | — | 小额 IAP |

**核心机制（为什么这样分）**：
1. **免费 5 局/日 = 一次半的天梯体验**。天梯 BO3 一场 = 2~3 局，5 局足够每天认真挑战 1~2 次，也足够让败局后的"再来一局"冲动溢出 → 自然流向广告加局或订阅。
2. **3 局直接发放 + 2 局广告兑换**：厂商实付保底按 3 局/日计（≈0.09 元/人/日），广告兑换的 2 局由广告主付费 ≈ 单局 0.03 元，**基本等价覆盖**。这把"免费玩家成本"从 5 局压到 3 局，是整份方案的成本命门。
3. **订阅卖"解除等待"，不卖"更强的局"**：订阅者日上限 20 局（人类正常打不满，防脚本刷），不降难度、不加命中、不送进度。免费与付费面对完全相同的对手与判定。
4. **新内容"提前玩"而非"独占"**：命题/NPC 先给订阅者试玩 2 周再进免费池——制造"订阅 = 第一批体验"的稀缺感，同时不把内容变成永久付费墙，保住免费玩家的 L5 可达性。
5. **单笔 IAP 与订阅并存**：皮肤/命题包可单买（吸引非订阅但想支持/想要外观的用户），避免"不订阅就什么都买不到"的粗暴二选一。

**必须免费否则崩的清单（任何一项被做进付费，立即回滚）**：

| # | 必须免费的东西 | 为什么 |
|---|---|---|
| 1 | 六维雷达图 + 软肋可视 + 每次判定标签 | "先读懂再出拳"的情报前提（P1）；读图付费=把玩法地基当商品 |
| 2 | 克制版基础复盘（1 次/局免费） | 学习闭环的入口（"我为什么输"必须人人都能看）；复盘加价只能加克制维度（§2 #6） |
| 3 | 天梯 L1–L5 全部对手 + 基础命题 | **免费玩家能打到 L5** 是"付费不影响进度上限"的承诺；钱只买重试频率，不买通关资格 |
| 4 | NPC 记忆/成长/翻旧账 | 支柱 2「对手是活的」人人可体验；记忆容量不做扩容付费（§2 #15） |
| 5 | 游戏内 token / 时间配额本身 | 资源压迫是乐趣（P3）；任何用真钱直接换 token/延长的入口都不存在 |
| 6 | 基础 NPC 语音 / 打字机演出 | 演出是"活的对手"的基础层；音色**包**（额外款）可卖，默认款不卖 |
| 7 | 教练提示（卡壳救援） | "怕你输而收钱"在克制设计里是不成立的；提示是宽容设计，免费 |

### 3.2 变体 B：订阅重度（运营期）

| 项 | 内容 |
|---|---|
| 结构 | 免费 3 局/日（全部直接发放，不加广告兑换额度）；订阅 18~25 元/月，含全部外观 + 全部内容 + 赛季通行证；单笔 IAP 收窄为"限定皮肤/赛季礼包" |
| 思路 | 提高订阅价 + 压低免费额度 = 更强的转化压力；靠赛季/赛事通行证维持续费 |
| 适合阶段 | **稳定运营期**：已有渠道（小程序/平台）、DAU > 5k、能做赛季与榜单运营，内容更新节奏稳定（周更命题） |
| 代价 | 免费体验偏紧（3 局/日），对"分享裂变/口碑"友好度下降；首月流失风险高于方案 A |
| 与 A 的关系 | 方案 A 数据跑出"免费转订阅主要靠局数用完瞬间"，再考虑收紧到 B；**不直接上 B** |

### 3.3 变体 C：一次性买断（解锁全部）

| 项 | 内容 |
|---|---|
| 结构 | 买断价 45 元（V1 现有 5 NPC + 50 题全量），含全部外观与克制战绩；日上限提至 20 局（反滥用）；后续新 NPC/命题以扩展包 DLC 另计（6~12 元） |
| 思路 | 一次付费、永久当前版本内容；无订阅压力、无广告；最接近"独立单机买断"的体感 |
| 适合阶段 | **无订阅运营环境 / 独立发行 / 买断制渠道**（Steam 类 / 一次性买断 H5 商城）、低 DAU 情怀场景、或赛后想快速回本的小规模发行 |
| 致命弱点（必须正视） | "一次付费 + 永久开口"与"LLM 成本随开口线性增长"**本质冲突**：重度长留玩家每年对局可达 3,000+（20 局/日 × 150 天）→ 单用户年 LLM 成本 60~90 元 @0.02，**超过 45 元买断价**。买断制的毛利不是稳定常数，是"平均局数 × 成本"的敞口 |
| 缓解 | ① 20 局/日软上限（人类打不满、脚本打不穿）；② 对局数做**存档级统计**做异常预警；③ 内容扩展开 DLC 让重度玩家持续二次付费；④ 明确"买断=内容买断，不承诺永久免费算力"的文案边界（发布层法务） |

### 3.4 三案对比与阶段建议

| 维度 | A 免费增值（推荐） | B 订阅重度 | C 一次性买断 |
|---|---|---|---|
| 单位经济 | 优（订阅+广告+单笔三腿） | 中（依赖转化率） | 差（成本敞口 + 无复购） |
| 玩家口碑/吃相 | 好（外观+频率付费） | 中（免费偏紧） | 最好（干净） |
| 对赛事/评审 | 无影响（正式版再启用） | 无影响 | 无影响 |
| 运营投入 | 中（赛季/内容更新） | 高（持续运营） | 低（交付即完成） |
| 最适合阶段 | **试运营 → 放量（默认）** | 稳定运营期 DAU>5k | 独立/买断制渠道、低 DAU 情怀场景 |

> **建议路径**：参赛/冷启动期只跑"无内购收入"（打赏 + 广告，见 §4.5 渠道说明）；拿到资质/渠道后按 **方案 A** 上线；A 的数据证明"局数用完→订阅"漏斗有效后再考虑向 B 收紧；C 只在出现买断制渠道（独立发行）时启用。

## 4. 数值草案

### 4.1 成本口径（来自 ENG-002，本方案的计算前提）

- 单局 LLM 成本：**0.03 元/局**（推荐异构方案 12 回合，无缓存，保守上界）；**0.02 元/局**（prompt 前缀重构打缓存 90% 后，工程手段 #1/#2/#6 组合）。
- 1 DAU（日均 3 局，全免费）月成本 ≈ 2.9 元（@0.03）→ 2.1 元（@0.02）。
- 天梯 BO3 系列赛一场 = 2~3 局；**"免费局数"须按 BO3 粒度设计**。

### 4.2 免费局数 X 与成本表

| 免费局/日 X | 月局数/人 | LLM 成本（元/人/月，@0.03） | LLM 成本（元/人/月，@0.02） | 换算成"天梯尝试" |
|---|---:|---:|---:|---|
| 3 | 90 | 2.70 | 1.80 | 约 1 次完整系列赛 |
| **5（推荐值）** | 150 | **4.50** | **3.00** | 1~2 次完整系列赛 + 1 次自由练习 |
| 8 | 240 | 7.20 | 4.80 | 2~3 次系列赛（偏重度） |
| 10（ENG 现行反滥用硬上限） | 300 | 9.00 | 6.00 | 不设为免费档（过贵） |

**推荐 X = 5 局/日**，其中：
- **3 局直接发放**（保底成本 2.70 元/人/月 @0.03，1.80 元 @0.02）；
- **2 局经激励视频兑换**（广告收入 ≈ 单局 0.03 元，基本覆盖自己的算力成本，保底成本不含这 2 局）。

> 这样"免费玩家体验 = 5 局"，"厂商实付保底 = 3 局"。X 低于 3 会毁掉每天一次完整天梯的体验；高于 5 则免费成本在 @0.03 下跨过 4 元/人/月，纯免费 DAU 压力过大。

### 4.3 定价与单用户单位经济

**成本假设**：订阅用户日均 6 局、免费用户日均实际 2.5 局（3 局上限常有未打满日）、内容安全/支付/人工另计（见 4.5 说明）。

| 收入项 | 定价 | 单用户月毛利（扣除对局 LLM 成本） |
|---|---|---|
| 月订阅 | **15 元/月** | 该订阅者月对局 ≈ 180 局 → LLM 5.4 元（@0.03）/ 3.6 元（@0.02）→ 毛利 **9.6 / 11.4 元** |
| 年订阅 | 128 元/年（≈10.7 元/月） | 现金流前置、流失成本降低，毛利优于月订（按年度算） |
| 单件皮肤（立绘+音色） | 6 元 / 件 | 纯资产成本，毛利 ≈ 定价 − 资产摊销 |
| 命题包（10 题/包） | 3~6 元 / 包 | 需计入审核 + 判定校准成本（一次性），运行成本 = 普通对局 |
| NPC 预设包（离线生成+人工审核） | 6~12 元 / 包 | 生成在配置阶段（gen_npcs），运行时成本与普通对局相同 |

### 4.4 DAU 盈亏场景表（免费增值 + 订阅 + 广告，方案 A）

**模型假设**：免费用户实际 2.5 局/日、订阅用户 6 局/日、订阅 ARPPU=15、广告收入 0.5 元/月/免费用户（约 1 次/2 天观看）、单笔 IAP/打赏另计。

| 订阅渗透率 r | 加权局数/日 | LLM 成本（@0.03，元/DAU/月） | LLM 成本（@0.02） | 收入（订阅+广告，元/DAU/月） | 毛利 @0.03 | 毛利 @0.02 |
|---|---:|---:|---:|---:|---:|---:|
| 0% | 2.5 | 2.25 | 1.50 | 0.50 | −1.75 | −1.00 |
| 5% | 2.68 | 2.41 | 1.61 | 1.23 | −1.18 | −0.38 |
| **8%** | 2.78 | 2.50 | **1.67** | **1.66** | −0.84 | **−0.01（盈亏平衡）** |
| 12% | 2.92 | 2.63 | 1.75 | 2.24 | −0.39 | +0.49 |
| 20% | 3.20 | 2.88 | 1.92 | 3.40 | +0.52 | +1.48 |

**结论（三条，务必看）**：
1. **@0.03 下需要 ~15% 订阅渗透才盈亏平衡，@0.02 下只需 ~8%**。单局成本从 0.03→0.02 不是"省 1 分钱"，是把目标转化率从几乎不可能的 15% 拉到现实的 8%——**成本优化（前缀缓存 + 异构 + 低 TTFT 模型）是商业模式成立的前提，不是可选项**（对齐 ENG-002 §4）。
2. 若再计入皮肤单笔与打赏（约 +0.3~0.5 元/DAU/月收入），**@0.02 + 6~8% 渗透即可转正**。目标经营线建议：**渗透 8~12%、ARPPU 18~20 元、单局成本 ≤0.02** → 单 DAU 月毛利 +0.3~+1.0 元（1 万 DAU 月毛利约 +3k~+10k，未计渠道抽成与人力）。
3. **免费 DAU 本身就是成本**（r=0 时每 DAU 月亏 1~1.75 元，由付费与广告补贴）。因此"自然量免费玩家"不是免费的——**获客预算要按 1.0~1.75 元/DAU/月的补贴成本规划**（即 CAC 实际要倒扣这部分）。

### 4.5 一次性买断经济学（变体 C）

| 场景 | 年对局数 | 年 LLM 成本（@0.02） | 买断价 45 元毛利 |
|---|---:|---:|---|
| 轻玩家（买断后偶尔玩） | 60~150 局 | 1.2~3.0 元 | +42~44 元 |
| 典型玩家（每周 3 次） | 300~600 局 | 6~12 元 | +33~39 元 |
| 重度长留（20 局/日 × 150 天） | ~3,000 局 | ~60 元 | **−15 元（亏）** |

> 买断对"典型玩家"毛利健康，但**重度长留是负毛利敞口**。因此 C 方案必须：① 日上限 20 局软上限；② 把新内容做成 DLC 让重度二次付费；③ 只在"低 DAU + 买断渠道"使用（此时重度长留比例可控）。**C 不适合 DAU > 3k 的规模运营。**

### 4.6 渠道限制说明（设计层立场）

- 国内 Web 无版号不能内购 → 方案 A/B/C 的"订阅/买断/IAP"都依赖**具备资质的发布渠道**（微信小程序、安卓/苹果、独立买断商城），落到发布层决定。
- 无版号阶段可先跑的收入：**广告（激励视频）+ 打赏**——两者不依赖内购资质，且与本文模型兼容（广告已作为免费档第 4~5 局的支付方，打赏作为补充腿）。
- 本文所有数字是"如果收费该收多少"的设计答案；是否/何时能收由主理人与发布层裁决。

## 5. 与现有系统的衔接

### 5.1 局数/体力计数落点（progress.json → 服务端 user_state）

现状：`demo/data/progress.json` 只有 `{"highest_cleared": 0}`，无用户身份、纯本地。单机 demo 期不需要计数；商业化后对局成本与局数必须**服务端权威计数**（客户端计数可被伪造）。

建议演进（渐进，不推翻 demo）：
1. **demo/单机期**：沿用本地 `progress.json`，只在 `highest_cleared` 上加 `daily` 计数（可暂不做，因为没有线上成本风险）。
2. **商业化最小版**：新增服务端 `user_state/<uid>.json`，职责 = 进度 + 配额 + 权益；`npc_state/<uid>.json` 承接记忆/成长存档（记忆与成长是"玩家与 NPC 的关系"，绑定 uid 而非设备）。
3. 目标 schema 草案（给工程，非本文实现）：

```jsonc
// user_state.json（服务端 per uid；沿用 harness F1 状态层"服务端权威"思路）
{
  "uid": "wx_openid_xxx",
  "progress": { "highest_cleared": 3, "unlocked": ["L1_A", "L2_A", "L3_A"] },
  "quota": {
    "date": "2026-09-08",
    "direct_used": 2,        // 直接发放 3 局/日，已用 2
    "ad_redeemed": 1,        // 广告兑换 2 局/日，已用 1
    "sub_unlimited": false   // 订阅者此字段 true，走 20 局/日软上限
  },
  "entitlement": {
    "subscription": { "tier": "monthly", "expire_ts": 1780000000 },
    "owned": { "skins": ["wangayi_nyc"], "topic_packs": ["politics_01"], "npc_packs": [] }
  }
}
```

**配额扣减规则（服务端）**：每局 `new_session` 创建时校验当日配额 → 通过才允许进入 LLM 调用链；对局中途崩溃/断线**不算消耗完整一局**（收到局终回调才正式扣减，防"网络差等于被吞局"的退款投诉）。

### 5.2 对天梯解锁的影响（免费玩家能打到 L5 吗？）

| 问题 | 答案 |
|---|---|
| 免费玩家能否打到 L5？ | **能。** L1–L5 与 50 基础命题对所有玩家开放，进度只受 `highest_cleared` 解锁逻辑控制（战胜本层解锁下一层），与付费状态无关 |
| 付费影响什么？ | **只影响重试频率与等待**：免费 5 局/日用完就等明天（或广告加 2 局）；订阅者当天可无限重试（软上限 20 局）。卡 L4/L5 的玩家要么次日再来，要么订阅"今天打穿"——**这是付费动机，不是付费门槛** |
| 会不会"付费=进度快"？ | 会快在"次数多、练得多"，但每局对手与判定完全相同，玩家能力提升是真功夫 → 快慢不破坏天梯可信度（对齐红线 R1） |
| 自由切磋模式 | 与天梯同一套局数配额（成本是同一份）；订阅者同样无限。自由模式是"试打法/演示 AI 原生"的沙盒，不另设体力 |

### 5.3 防小号刷局的最小对策

LLM 成本最大的风险不是正常玩家多，是**脚本刷量**（ENG-002 §3.1：100 个脚本号 ≈ 10 万/月）。免费局数 + 商业化会放大养号动机，最小对策如下：

| 对策 | 说明 | 优先级 |
|---|---|---|
| **uid 主键 + 服务端权威计数** | 微信登录 openid / 设备指纹作 uid；配额只在服务端扣减，客户端不可信 | P0 |
| **IP 级与设备级聚合上限** | 单 IP ≤30 局/日（ENG 已有）；**单设备 ≤15 局/日（跨 uid 聚合）**，堵"一台设备切 5 个号各打 5 局" | P0 |
| **广告兑换走平台回调验签** | 激励视频"加局"由广告平台服务端回调发放，禁止客户端自行上报"看完了" | P0 |
| **免费局不结转 + 新号权益缩水** | 3 局直接发放当日作废不累计；新 uid 首日额度减半或需完成新手局才解锁全额——降低"注册即薅 5 局"的号海 ROI | P1 |
| **风险风控抽查** | 同设备短时间多 uid / 新号首日即打满 → 升级要求微信登录或人工验证 | P1 |
| **性价比自限** | 一个号一天只值 0.09~0.15 元（3~5 局 × 0.03），刷号收益极低；IP/设备聚合后基本不值得规模化 | — |

### 5.4 与复盘克制 / 记忆成长 / 数值表的边界

1. **复盘克制是硬约束**：付费"深度复盘"只能增加表达质量维度的标签与时间线统计，**禁止出现任何六维数值、软肋点位、"打哪一维"建议**——付费不能买到 systems-v2 §1 明令禁止的攻略层信息。实现上深度复盘 = 同一份克制 prompt 的"更多切面"，而不是换一个"不克制"的 prompt。
2. **局数配额是成本护栏，不是玩法参数**：免费局数上限不与 game token 配额、六维难度、漂移参数共用同一张数值表（F8 `value_tables.json` 只管平衡参数）；配额属**用户态计数**（user_state），不属平衡参数，**不要把 quota 写进 `value_tables.json`**（避免"调平衡"误伤"烧钱护栏"）。
3. **记忆成长不付费扩容**（§2 #15）：记忆保留 3 局、摘要 ≤45 字是成本护栏 + 玩法设定，保持不变；商业化不碰它。

## 6. 风险与缓解

| 风险 | 触发场景 | 影响 | 缓解 |
|---|---|---|---|
| **付费变强 / 支柱漂移** | 运营压力下想卖"延长 token""跳过等待""读心道具" | 核心乐趣与公平崩坏；与总纲支柱红线直接冲突 | 红线 R1/R2/R3 写入代码层可配置白名单：**付费点枚举表里凡触碰"赢/说/看"一律不允许上架**（新增付费点需过设计评审，由主理人/大王拍板） |
| **被骂吃相 / 口碑崩** | 广告打断对局、失败后"充值才能复盘"、体力逼氪 | 杠精/表达者用户群对"被按头付费"极敏感，舆论反噬快 | 广告只在非对局场景（失败结算页/每日加局页）；复盘基础版免费、克制；免费 5 局/日足够体验核心循环；**"差一局就赢"的付费转化靠口碑而非威逼** |
| **内容安全/审核成本被低估** | 命题包/NPC 包量产 → 每批都要过内容安全 + 判定校准 + 人工审核 | 题材质量是成本（题面已提示），审核人力与违规下架风险 | 命题包走与基础题库相同的 B6 敏感过滤 + 判定测试集流程；NPC 包走 gen_npcs 离线生成 + 人工审核；**把审核成本计入话题包定价**（3~6 元已含摊销） |
| **无版号 Web 内购合规** | 直接在国内 Web 上订阅/买断 | 违规、下架 | 内购全部走具备资质的发布渠道；无版号阶段只跑广告 + 打赏（§4.6） |
| **广告合规 / 未成年人** | 激励视频诱导误触、广告内容不适、未成年人付费 | 平台处罚 + 退款纠纷 | 广告按钮明确标注"观看后 +1 局"、不得伪装成关闭按钮；未成年人保护：支付需实名，订阅需家长确认（发布层政策） |
| **退款 / 纠纷** | ①失败后情绪化申请"服务不满意"退款；②订阅自动续费争议；③号被封后申诉 | 对局 LLM 成本已实际消耗（不可退），退款=双重损失 | ①对局日志留痕（judge 判定/NPC 调用记录，ENG-002 已有埋点要求）作为服务已提供的凭证；②订阅自动续费提前 7 天提醒、随时退订、未消耗权益可退；③封号提供申诉通道，明确"刷号违规"条款 |
| **供应商涨价击穿模型** | 2026 已发生国产大模型集体涨价 | 单局成本上行 → 盈亏线右移 | 依赖 ENG-002 ADR-006 多供应商路由表：至少 2 家已跑通，季度复核价格；**定价与免费局数都按"当前成本 ×1.5 安全系数"校准，给涨价留缓冲** |

## §A. 三个原始想法的裁定表（详细）

### A.1 裁定总表

| 想法 | 可行 / 需改写 / 否决 | 核心理由（为什么） | 替代方案（怎么办） |
|---|---|---|---|
| 1 · 充值买 token | **需改写：标的否决、充值行为成立** | "token"若指游戏内发言额度（L1=420→L5=280，DES-004 红线 R2），直接卖它 = ①卖"说得更多"= 卖核心压迫感（P3）；②单局 LLM 成本随开口线性放大（每回合 ~2 次调用），是**设计上最贵、体验上最伤**的双输项。ENG-002 §1.5 已澄清：游戏内 token（口舌）≠ LLM token（算力），两者零换算关系。若大王另指"花钱给 NPC 买更聪明的脑子"，那同时踩 R1/R3，更不可行。**但"充值"作为商业模式动作完全成立**，要改的是标的物 | 充值只买 A.2 的「频率 / 身份 / 内容」三桶；要"可消耗资源"体感 → 买**天数卡**（时间型资源），不做局券（A.3 论证） |
| 2 · 看广告换 token | **可行（需改写为"广告换频率与救援"）** | 广告=用时间换资源，人人时间预算相近且可加日上限，**不会制造"有钱人更强"的不公平**，破坏性低，方向正确；但广告**同样不能**换单局内 token/时间扩容（R2 的边界不在"用钱买"而在"买开口量"本身，换支付手段不改变违规性质） | 完整广告经济系统见 §B：换「失败重开 / 当日加局 / 提示券 / 皮肤音色试用 / NPC 叙事档案」，统一 8 次/日配额、局内零广告 |
| 3 · 教练提示做成广告换 | **需改写：否决"全广告换"，采纳"免费低频 + 广告补量"** | 教练提示单次 ≈0.001 元（529 token 输入），成本低到不值得收钱；且提示是**宽容设计**（"怕你输而收钱不成立"，v0.1 必须免费清单 #7）。三档对比见 §C：全广告换会把"卡壳最痛时刻"变成广告拦截点，把失败焦虑变现，口碑崩 | 免费 2 次/局保底（订阅者给 5 次/局不弹广告）→ 超出部分可**对局外**看 1 个广告囤"+3 次券"；现金不出售；局内静默消耗、绝不弹广告 |

### A.2 「充值买什么」才成立——对价三桶表

> 判定规则一句话：**充值成立 ⇔ 对价落在 {频率, 身份, 内容} 之一；对价落在 {强度(R1), 开口量(R2), 情报/生成入口(R3)} 即否决。**

| 桶 | 玩家付费买的本质 | 推荐产品 / 定价（沿用 v0.1） | 红线检查 |
|---|---|---|---|
| **频率**（解除等待） | "今天还想再打两局 / 不想等明天" | 月订阅 **15 元/月**（无限局 + 20 局/日反滥用软上限）；**天数卡 3 天 6 元 / 7 天 10 元 / 30 天 15 元**（新增，见下） | 不碰单局 token、不碰判定 |
| **身份**（好看 / 独特） | "想让我和对手更好看 / 有排面" | 皮肤 / 立绘 / 音色包 **6 元**、称号 / 头像框 / 结算演出（随通行证，见 §D-D1） | 纯外观，零强度 |
| **内容**（新题 / 新对手） | "想辩一道新题 / 会会一个新 NPC" | 命题包 **3~6 元**、预设 NPC 包 **6~12 元**（gen_npcs 离线生成 + 人工审核后的**成品**） | 只卖成品，不卖生成能力 / 不卖数值 |
| **永不（红线）** | 更强 / 更多话 / 更透 | — | R1 / R2 / R3 全否决 |

**天数卡说明（这是对"充值换可消耗资源"体感最接近且不破红线的替代）**：
- 让玩家在界面上看到一个"**30 天倒计时在消耗**"，充值 = 购买"畅玩期限"，**消耗的是时间不是口舌**；本身体感是"我买的权益在被用掉"，满足大王想要的"可消耗资源"手感。
- 定价锚：**3 天 6 / 7 天 10 / 30 天 15**（短期卡单日价高于月卡 = 便利溢价，自然把高频玩家导流去月卡）；单笔 ≥6 元，天然避开虚拟支付"单笔最低 1 元"门槛 + 高频小额退款纠纷（REL-001 §4.3）。
- 成本护栏不因按天售卖而失效：**20 局/日软上限照常生效**。3 天卡重度用户最多 60 局 × 0.045 ≈ 2.7 元成本 < 6 元售价，毛利健康。

### A.3 为什么"单售重开一局券"不好，而会员 / 天数卡好

> 大王若坚持"充值换可消耗资源"且点名"重开一局券"——它本质是**按局收费的变形**，逐条否决如下：

| 维度 | 单售"重开一局券" | 会员 / 天数卡 | 结论 |
|---|---|---|---|
| **单价锚定** | 一局真实成本 0.045 元，心理合理价 <0.5 元，但支付通道单笔最低 1 元 → 要么亏、要么一局卖 1 元显得离谱 | 一单 ≥6 元对价"一段时间内无限畅玩"，锚定合理 | 局券定价两头不讨好 |
| **玩家心理** | 把"输一局"直接换算成"亏了钱"，失败瞬间弹付费 → **把每一局变成风险投资**，止损焦虑污染"压迫感是乐趣"（P3） | 钱整体化后，"多打"= 值回票价，厂商希望你赢、你玩得爽 | 局券让"输"变负资产 |
| **激励一致性** | 厂商利益 = 希望你多输多买。**哪怕实际不做，玩家也会怀疑判定偏严**——直接伤"AI 是公平裁判"的信任（支柱 4） | 厂商利益 = 你续费 → 与你赢的方向一致 | 局券制造猜疑 |
| **合规 / 渠道** | 局券是典型"游戏虚拟道具"，最易触发版号口径与"游戏类目"判定；支付审核面大 | "工具/陪练 + 订阅/服务时长"边界相对清晰 | 局券合规面更差 |
| **成瘾 / 未成年人** | 高频小额冲动消费，退款纠纷多、未成年人风险高 | 低频大额 + 家长确认门槛更可控 | 局券风险更高 |

> **记忆句：局是压迫感，天是畅玩权。想续命就续天（会员/天数卡），别给单局标价。**

## §B. 广告经济系统设计（想法 2 落地版）

### B.1 统一配额模型（先定总账）

- **每日广告观看总配额 N = 8 次/日/用户，所有出口共享同一计数器**；用尽后全部出口置灰并提示"明日再来"，不提供绕过。
- **与 v0.1 免费局数的关系（回答题面）**：v0.1 方案 A 的"3 直发 + 2 局广告兑换"是**同一套广告库存的两个出口，不是独立额度**。即：广告局的 2 局也消耗 N，不是另开一池。**（增补说明 [增补-1]：兑率校准见 B.2 与拍板点 #12。）**
- **eCPM 口径**：0.02~0.06 元/次（激励视频国内大盘，沿用 v0.1，置信度：中；填充率与价格随季节/行业波动，接 SDK 后按滚动 7 日 eCPM 实测调价）。取**中值 0.04 元/次**做测算。
- **兑换定价原则**：厂商边际成本 ≤ 广告收入 × 0.5~0.7 才放行（不做亏本兑付）；运营期兑率**数据化配置，不改代码**。价目表按"滚动 7 日 eCPM ÷ 目标兑付比"自动生成建议值，人工复核后生效。

**默认配额画像（N=8 的一种典型分法，给运营参考，非硬性拆分）**：

| 出口 | 消耗配额 | 说明 |
|---|---:|---|
| 2 个广告局（v0.1 的免费第 4~5 局） | 2×2 = 4 | 兑率 2 广告/局（保守覆盖含审核成本） |
| 失败重开 | 视需求 0~2 | 每失败局限 1 次重开，见 B.2 #1 |
| 提示券（超量示范） | 0~2 | 1 广告 = +3 次，见 §C |
| 皮肤音色试用 / NPC 档案 | 0~2 | 1~2 广告，见 B.2 #5 #6 |
| **合计** | **≤ 8** | 封顶，防平台风控 + 防体验崩 |

### B.2 广告可换标的清单与定价（≥6 项 + 1 否决位）

|---|---|---|---|---|---|---|---|
| 1 | **失败后重开本局**（同题同对手再打一次） | 5 | =1 局成本 0.03~0.045 | **2 个/局** | 0.08 ≥ 0.045，稳覆盖 | **S（头号出口）** | 做。仅"失败结算页"入口；每失败局限 1 次；重开计入当日局数上限与广告配额。**胜利局不提供**（避免"赢了还想刷"的奖励错位） |
| 2 | **当日加局**（免费 3 局之外，v0.1 的"2 局广告兑换"即此出口） | 4 | =1 局成本 0.03~0.045 | **2 个/局**（增补校准，见 [增补-1]） | 0.08 ≥ 0.045 | **S（沿用）** | 做。每日加局页/续战入口；上限 2 局/日（即 4 配额） |

| 4 | **开战前额外换一题**（第 2 次起） | 2~3 | ≈0（题库随机，不触发 LLM） | 1 个/次 | 纯利润 | **C（默认不做）** | 现状免费重摇保留（v0.1 §2 #10 承诺），**默认不进广告出口**：省 0.04 元 vs 毁开局流畅与好感，不划算。若大王要第 6 个出口再放行，见拍板点 #14 |

### B.3 频次上限与防骚扰

| 项 | 建议值 | 理由 |
|---|---|---|
| 单用户日观看上限 | **8 次/日（N），出口共享** | ①国内主流激励视频 SDK 单设备日展示频控约 10~15 次，自设 8 次主动低于平台线，防风控误伤；②防体验崩——8 次全部主动点击已是重口，超过=骚扰 |

| 允许的点位 | 对应出口 | 绝对禁止 |
|---|---|---|
| 失败结算页 | #1 失败重开 | **对局中任何打断性广告**（含回合间隙） |
| 每日加局 / 续战页 | #2 加局 | 结算页"必看广告才能看复盘"（复盘基础版免费，v0.1 必须免费清单 #2） |
| 对局外"囤券页"（选边前 / 结算后可进入） | #3 提示券、#4 换题（若放行） | 广告奖励与"胜率/进度/判定"任何形式的挂钩 |
| 结算后种草位 | #5 皮肤试用、#6 NPC 档案 | 诱导误触的插屏 / 全屏霸屏广告 |

> **设计红线重申**：广告换的全是「再试一次 / 今日加局 / 救急示范 / 试吃 / 叙事内容」，**任何出口都不产出"单局内更强、更多话、更透"**——与 v0.1 三条红线同源同界。

## §C. 教练提示（💡 卡壳救援）三档裁定（想法 3）

**事实基座（决定判定的关键）**：教练提示单次 = 529 token 输入 + ~40 token 输出，成本 ≈ **0.001 元/次**（ENG-002 §1.2；按侧路便宜模型更低）。v0.1 将其列为"必须免费"（宽容设计："怕你输而收钱不成立"）。代码现状：免费且**无限次、无计数**（`server.py /api/hint`）。

| 档 | 结构 | 宽容度 | 对"读懂"支柱（P1/P3） | 成本 / 收益 | 判定 |
|---|---|---|---|---|---|
| **A · 完全免费（现状）** | 每局不限次 | 最高 | **弱侵蚀**：hint 每次都会点名薄弱点 + 给针对话术，无限次=可当"软肋查询器"每回合刷一次，"先读懂再出拳"被免费代劳 | 若每局平均点 5 次 ≈ 0.005 元/局（≈局成本 10%+ 白白烧掉）；无商业价值 | 可行但不推荐（无节制 + 无商业出口） |
| **B · 免费低频 + 广告补量（推荐）** | 免费 **2 次/局**（订阅者 5 次/局、不弹广告）；超出 = 局外看 1 广告囤"+3 次券"，局内静默消耗 | 高（救命的前 2 次无门槛） | **守住**：次数封顶，避免无限查询；超量需玩家主动在局外花时间，有节制、有"珍惜使用"感 | 2 次免费 ≈ 0.002 元/局（可忽略）；广告补量几乎纯利（1 广告 0.04 ≈ 40 次 hint 成本） | **★ 推荐** |
| **C · 全部广告换** | 0 免费，全部要券 | 最低 | 卡壳最痛时先被广告拦截 → 把失败焦虑变现 | 单用户广告收益略高，但宽容设计崩 + 口碑反噬 | **否决** |

**推荐 B 的三条理由**：
1. **别为省 1 厘钱毁宽容**：2 次免费的成本 ≈0.002 元/局，相对局成本 0.03~0.045 是 4~7%，完全可负担；基础提示收费所省的，远小于口碑损失。
2. **真正的账不是钱，是"读懂"支柱**：无限免费提示才是问题（档 A 的软肋查询器风险）。给提示设**每局 2 次上限**不是砍福利，而是让"卡壳救急"回归救急、不让它代打"读人"——这比收不收费更重要。
3. **广告是可选收入不是门槛**：就算没人看广告囤券，2 次免费也够绝大多数人救急；广告出口自然空转无害——因为基础免费不动，宽容不破。
4. **合规边界**：hint 内容只是**复述雷达图已免费可见的软肋 + 示范话术**，不泄露任何隐藏数值（R3 针对的是付费买隐藏情报；这里情报免费、只限频，且现金永不卖）。

> **（增补说明 [增补-2]，待大王拍板后回写 v0.1 必须免费清单 #7）**：将"教练提示免费"界定为——**基础免费 = 每局前 2 次（订阅者 5 次）无门槛**；超出部分仅可用"局外看广告囤券"获得，**任何现金不卖提示**。基础提示 + 首次免费承诺不变。

### D1 · 赛季通行证细化——如何让"想上分想变强"的玩家自然付费而不碰红线

- **免费线（0 元）**：打完赛季任务（"累计赢 15 场 / 用证据维度赢 5 场"这类练习型任务）→ 领基础外观 1 件 + 赛季称号。
- **进阶手册（¥25/赛季，约月频）**：解锁全部外观 / 头像框 / 结算演出 + 赛季专属话题包提前玩 + **训练挑战任务池**（"这周专练『认同』维度打 8 局"）。任务只给**赛季积分 → 只换装饰**。
- **红线护栏（写死）**：① 通行证**永不加速天梯段位、不加胜率、不加命中、不加局数**（局数归订阅管）；② 经验/进度加速类一律不做（那是变相卖进度）；③ 段位、胜率、判定永远与付费状态零相关。→ 玩家为"这赛季我要集齐 / 想有个目标练嘴皮子"付费，**不是为排名付费**。赛季是订阅续费的最好内容钩子（对齐 v0.1 §2 #9，这里是细化落地）。

### D2 · 语音：ASR 免费配额 + NPC 音色包（含 ASR 云端成本口径）

- **产品结构**：ASR = 玩家语音转文字（替代打字），做**免费前 N 句/日 + 订阅不限但设日句数硬上限**（v0.1 §2 #7 已有方向）；NPC 音色包 = 一次性单买（TTS 授权/合成入资产，对齐 v0.1 #2）。
- **ASR 云端成本口径（量级预估，置信度低，需程基岩询价后定 N）**：按主流云厂商语音识别计费（按次或按时长），单句（≤8 秒）量级约 **0.002~0.01 元/句**。**上界警示**：若 0.01 元/句 × 每日 20 句 = 0.2 元/人/日 ≈ 6 元/月，会直接吞掉免费 DAU 预算；即便按 0.003 元/句（一句话识别档），20 句 ≈ 1.8 元/月，仍占 LLM 月成本的一半量级。**因此：N 必须在询价后拍板，建议 10~20 句/日起步；语音只是输入通道，每句语音仍会触发判定 + NPC 两次 LLM（局成本已计），ASR 是在局成本之上叠加的费用，语音重度局约等于成本翻倍——绝不做"语音无限免"**。
- **护栏**：① 免费低频配额；② 订阅"不限"是相对的——必须设日句数硬上限（防脚本）；③ 语音入口只在"口才练习"模式默认开，天梯首屏不开，避免把每局都逼成全语音。

### D3 · 观战 / 围观：边际成本验证与变现评估

- **验证（回答题面）**：观战只**回放已生成内容**——回放 = 服务端把对局中已存的 history（server `sessions` 内存 + 落盘日志）以文本流/静态页输出，**不新增任何 LLM 调用**；实时跟看 = 广播同一份 NPC 流式输出，**一份 LLM 结果多播，同样不新增调用**。观众边际成本 ≈ 带宽（每观众每局 <100KB）+ 静态存储 → **边际成本 ≈ 0，确认这是一个未被开发的低成本点位**。
- **变现评估**：卖门票 / 付费观看高分局，技术上成立、成本≈0，但 ① 纯文本对局的可看性弱于直播（缺演出）；② 观众付费意愿存疑；③ 若实时无延迟公开，可能被用作场外报点 / 抄题，需**延迟 ≥30 秒公开**才不影响公平。
- **裁定**：**免费开放为社区功能（拉活 / 拉新），配"打赏/应援"做非强度回馈（对齐 v0.1 #12，只给纯称号）**；不单独售票。若未来做官方赛事直播，观战位可作赛事门票 / 赞助位，那是赛事化的事，不是日常变现。
- **依赖**：SSE/回放接口属 P2 工程（ENG-002 §5.1 #6/#7），观战功能排队在工程就绪之后。

### D4 · 线下 / 内容衍生：金句卡、金句集、AI 人格报告分享卡

- **金句卡/金句集**：系统自动收录"被判定认可的高光句"（judge 判定为强论证的回合），生成**分享卡**。传播裂变 = 省 CAC（1 张被转发的卡 ≈ 免费获客），与"口才表达"定位天然契合。
- **AI 生成"你的辩论人格报告"**：基于玩家**本人**的克制统计（胜率 / 常用维度 / 表达质量时间线，不涉及任何对手数值）生成人格标签 → 分享。基础版**免费生成**（拉新工具）；深度版（更多标签维度 + 历史趋势 + 多赛季对比）随订阅或单笔 6 元（对齐 v0.1 #13 战绩档案）。
- **合规坑（必须先堵）**：分享卡上的 **"AI 生成"显式标识是强制的（《标识办法》第 8 条，REL-001 §2.4），任何"付费去 AI 水印 / 去标识"服务 = 违反规定，明确禁止作为付费点**。能卖的是**精修模板 / 边框 / 字体**，不是"去标识"。

### D5 · 企业 / 教育 B 端（一句话级评估）

同一个引擎的第二个市场：**AI 口才陪练 / 辩论教练 SaaS**，客群 = K12 口才班、职场表达培训、律所模拟庭训、企业内训。差异在题库换成合规职场/教育议题 + 账号 / 数据隔离 / 合同 / 开票 + 报告可导出。**一句话裁定：不在 MVP 与参赛期做**（需要主体升级、2B 交付人力、售后 SLA）；但建议在复盘导出与评分报告结构上**留 2B 接口**（低成本后置，日后不用重写数据层）。

### E.1 服务器成本口径（数据来源 REL-001 §3.1 / §8）

| 项 | 成本 | 折算月成本 |
|---|---|---|
| 域名 .cn / .com | 30~100 元/年 | 2.5~8 元/月（走小程序免域名则 ≈0） |

| 微信云托管 | 15~60 元/月 | 15~60 元/月（弹性，0.25 核 0.5GB 约 14.28 元/月起） |
| **单机合计（含域名）** | — | **约 10~60 元/月** |

### E.2 服务器 vs LLM：谁是大头？在什么 DAU 档反超？

| 问题 | 答案 |
|---|---|
| 单台服务器（促销 6 元/月）何时被 LLM 反超？ | 免费 DAU 月成本 ≈3~4 元（LLM+审核口径，REL-001 C6），**约 1.5~2 个 DAU 起 LLM 就超过整台服务器** |
| 单台服务器（常规 40 元/月）何时被反超？ | 约 **10 个 DAU** 即反超 |
| 结论 | **服务器从来不是大头**：从个位数 DAU 起 LLM+审核就是成本主导，且占比随 DAU 摊薄。1,000 DAU 时服务器占比约 **1~3%**；即便被迫扩到多台（几千 DAU），服务器占比仍 <3%。**服务器的意义是并发天花板（触发扩容 / 体验崩），不是账单** |
| 并发天花板参考 | 2核2G 按 ENG-002 §5.1 建议并发信号量 16；SSE 长连接占带宽但文本流每局仅几十 KB、连接大部分空闲。单台稳妥支撑 **DAU ~300~500**（按峰值并发 ~10~15% 估算）；超出 → 上微信云托管弹性伸缩或加第二台。**这是程基岩的工程闸，不是定价问题** |

## §0. TL;DR（最终裁定，大王先看这一节）

- **账号池机制的最终裁定（一句话）**：**成立，且方向正确——把游戏内 token 从"单局一次性预算"升格为"账号级、跨局、可消耗的游玩权资源池"，红线 R2 不因此被踩；前提是"局内规则（420→280 上限、底扣 20、超 60 字 1/字、L0 罚、回合/时间上限）一条都不能被账号 token 放大"。**
- **红线 R2 表述改写建议**：由"不卖说得更多（单局内配额扩容）"→ **「不卖单局内扩容」**——跨局总量（账号 token / 天数卡 / 订阅 = 能开几局）可以卖，单局内扩容（把一局 420 变大、局内续命、暂停、加回合）永远不卖。两句记忆句见 §A.1。
- **本节的四件不迎合大王的诚实结论（先摆结论）**：
  1. **大王"单局 480"是误记**：代码真值是 420→280（分五层递减），480 是**秒**（`TIME_LIMIT_S`，单局 8 分钟），不是 token 配额。机制设计照 480 走会开错门槛（详见 §A.3）。
  2. **"说话在花钱"——精确答案是：钱烧在"轮次"，不是"字数"**。单回合固定 prompt 成本 ≈0.002~0.003 元，玩家 40 字只占回合输入的 ~1.2%，边际≈0；而**底扣 20/回合 恰好 ≈1 回合真实 LLM 成本**——账号 token 按现行规则天然近似"按轮次计费"，这一点是整份设计最扎实的地方。
  3. **"账号池抑制乱说话"是真实的但被高估**：局内抑制废话的第一道闸是单局配额 + L0 连击翻倍（早就存在）；账号池只是第二道跨局闸（"一局烂尾 = 烧掉下一局的预算"）。它管不住"一局内照样能说"——别指望靠它改话痨，真想改去调 L0 罚则。
  4. **"无限看广告"三宗罪全部成立，必须否决**；随机奖励有价值但只是辅助，主闸是**单日累计获得 token 封顶**（建议 600 ≈ 2 局）+ 观看软上限 15 次。

> **待大王确认后才能视为生效的整链（一句话）**：免费日发 900 token（≈3 局）→ 充值 1 元≈2,000 token（≈6~7 局，毛利 ~70%）→ 广告单次随机 80~220（期望 ≈150）、日累计封顶 600 → 教练提示第 3 次吃 20 局内 token。全部依赖埋点校准，见 §A.7。

## §A. 机制裁定与成本映射（本报告最有技术含量的一节）

### A.1 红线 R2 的关系改写——裁定：成立，不踩线；但必须改写表述

**裁定：账号池=卖"局次与游玩权"，与方案 A 早就允许的"订阅=无限局"同属频率桶（v0.1 §1.1 收时间与频率），不构成 R2。成立。**

为什么成立（对 P3 的破坏路径不同）：

| 维度 | 卖"单局内扩容"（旧 R2 对象） | 卖"跨局总量 / 账号池"（本机制） |
|---|---|---|
| 改变什么 | 把一局的 420 变大、暂停、续命 | 只决定"今天能开几局、能打多久的总开口预算" |
| 对 P3 压迫感 | **直接拔掉**：这一局内"token 会耗尽"的倒计时被取消——而这是每局必发生、人人相同的紧张 | **不改变任何一局的内部规则**：开门之后 420 照旧，还是同一场考试 |
| 对单局成本 | 延长发言=回合线性放大（每回合 2 次调用）→ 最贵的双输 | 每局成本上限天然受层配额+回合数钳制，跨局多打=订阅早已允许的行为 |
| 公平性 | 穷人一局富人三局（同一局内不公平） | 同一局内玩家永远公平；付费只买"重试频率"（对齐 v0.1 §5.2"付费影响重试频率，不影响判定"） |

**关键边界哨兵（防止账号池变相回潮 R2，写死）**：
1. **禁止"局内 token 耗尽后，用账号 token 现场续命 / 充值续本轮"**——那是 R2 回潮，一次都不行；
2. **禁止任何"账号 token 兑换本局内更高配额 / 更多回合 / 暂停卡"**；
3. 局内扣费规则（底扣 20、超字 1/字、L0 +10、连击翻倍）与层配额对**所有档位玩家完全一致**，不受付费状态影响。

> **记忆句（给大王）**：**单局规则人人平等、且不可买；账号 token 只决定"你能进几回这道门"——进门之后，每局都是同一场考试。**
> **红线 R2 新表述（建议回写 v0.1 §1.2 用）**：R2 = **不卖"单局内扩容"**（局内 token 上限 / 扣费规则 / 暂停 / 无限发言 / 加回合 / 时间上限，任何支付手段一律不卖）；**卖"能开几局 / 总开口预算"（账号 token、天数卡、订阅）属于频率桶，允许**。*（增补说明 [增补-5]：v0.2 §A.1 对"充值买 token"的"标的否决"仅在其指"局内发言额度扩容"时成立；账号池把标的改为"账号级跨局游玩权、局内规则不变"后，该否决不自动适用——需大王在 §F #21 明确覆盖 v0.2 的措辞。v0.1 必须免费清单 #5 同理改为"局内 token 上限不卖、账号级 token 可作游玩权出售"。）*

### A.2 成本映射实测判断——钱烧在"轮次"，不是"字数"

**大王断言"说话在花钱"——精确回答：真钱几乎全烧在"你多打了一轮"，不烧在"你多打几个字"。**

| 事实（ENG-002 §1.2 + server.py 实测） | 数值 |
|---|---|
| 单回合 LLM 输入 | ≈2,190 token（判定 644 + NPC ~1,545） |
| 其中玩家 40 字 | ≈27 token = **回合输入的 ~1.2%** |
| 单回合真实成本 | ≈0.002~0.003 元（未缓存 12 回合局 0.032→约 0.0027/回合；缓存 90% 后 ~0.0015~0.002） |
| 多打 1 中文字的边际成本 | ≈0.67 LLM token ×1~6 处重发 ≈ **0.0000005~0.000004 元/字（量级可忽略）** |

**推论（对定价最有用的三条）**：
1. **底扣 20/回合 与真实成本几乎精确同量级**：20 token ×（0.0001~0.00015 元/token，见 A.4）≈ 0.002~0.003 元 ≈ 1 回合 LLM 成本。**账号 token 按现行扣减规则天然近似"按轮次计费"——这是"说话在花钱"在轮次级上成立的原因，也是账号池能当成本代理的根本理由。**
2. **超 60 字按 1/字是纯"玩法税"，不是成本镜像**：它惩罚话痨是为了 P3 节奏与防刷屏，与 LLM 账单几乎无关（字数边际成本≈0）。它不影响账号池与成本的对应关系，因为大头永远在轮次。
3. **量化"少说几个字 vs 少说几轮"**：把每轮 100 字压到 60 字——每轮省 40 **账号 token**，真实 LLM 成本省 ≈0；把一局从 20 轮压到 12 轮——省 8 轮 × ≈0.0027 ≈ **0.02 元真实成本**（≈160+ 账号 token）。**结论：少说一轮省的钱 ≈ 少说几千字省的钱。**对玩家的正确翻译是"**精简到要点、尽快打穿，比删字更重要**"——这也正好是辩论教学想传达的。

### A.3 开局门槛机制与"单局 480"差异说明（冻结 vs 检查）

**代码真值核对（必须纠正的口径）**：
- 局内配额：L1=420 / L2=380 / L3=340 / L4=300 / L5=280（`npcs.json: token_quota`，裁决 A3 确认为真值）。
- `480` 只出现在 `TIME_LIMIT_S = 480`（**秒**，单局 8 分钟）+ `MAX_TURN = 20`。
- 局内扣减：`cost = 20 + max(0, 字数-60) × 1`；L0 追加 +10；**连续 L0 连击使 base 翻倍 20→40**（`TOKEN_L0_STREAK_DOUBLE`，v0.2 口述未含此项）。
- 大王举例"单局 480"应指 8 分钟时限被误记为配额。**若以 480 设开局门槛，L1~L5 玩家会被超门槛拒之门外（没有任何一层的冻结门槛需要 480）。**建议门槛一律取"目标层配额全额"（L1 开 420、L5 开 280）。

**冻结-返还 vs 余额即开——推荐冻结-返还**：

| 方案 | 语义 | 评价 |
|---|---|---|
| **A. 冻结-返还（推荐）** | 开局从账号池**冻结目标层全额 Q**；局内从冻结额扣减（规则不变，耗到 0=LOSE_TOKEN 照旧）；局终把 Q−实际消耗**返还池**。门槛=池 ≥ Q。 | ①"每开一局先押整份配额"的仪式感，让"这局在花我的钱"可见；②弃局/断线语义干净——按已发言实扣、余量返还，无退款漏洞；③与 v0.1 §5.1"局终回调才正式扣减"思路一致 |
| B. 余额≥Q 即开、局内从池实时扣 | 逻辑等价（因池≥Q≥局内余量，局内扣完前池不会先空），但弃局、体验、可解释性都更弱 | 简单但缺仪式感，弃局难记账 |

**微调建议（防"池子大→不珍惜"反效果，诚实版）**：P3 的紧张感来自**局内** LOSE_TOKEN / 绝望倒计时，与池大小无关——池化不会摧毁它。真实存在的反效果只有一个次要项：池大的付费玩家可能"乱开几局探路"（v0.1 订阅者本就如此，非新增风险）。对策不是把门槛抬过全额（会破坏"一局预算=层配额"的公平感），而是：① 保留冻结-返还的"押全额"仪式；② 结算页展示"本局实耗 X token · 账号剩余 Y"；③ 局内 player_emotion 的紧张 UI（代码 `_emotion`）原样保留。**结论：单局 480 上限保留 + 账号池只影响能开几局，玩家视角的紧张感还在。**

### A.4 换算锚：1 游戏内 token ≈ 多少元

> ⚠️ 语义澄清：这不是"1 token 可兑换 X 元现金"，而是"**烧掉 1 个账号 token 对应的预期 LLM+审核成本**"——用于定价/广告兑率的"不亏校验"，不用于向玩家出售 1:1 兑换承诺。

- 局级锚：典型局消耗 ≈300 账号 token（赢在 10~14 轮、均字 60~90 → 常见 250~400；层上限 L1 420 / L5 280；**待埋点校准**）× 典型局真实成本 0.03~0.045 元（LLM 0.021~0.032 + 审核 0.006~0.01）。
- 轮级锚（更稳）：底扣 20 token ≈ 1 回合成本 0.002~0.003 元。
- **建议取：1 游戏内 token ≈ 0.00015 元 ≈ 1.5 厘（保守口径，含审核）；纯 LLM 口径 ≈ 0.0001 元。换算即：1 元成本 ≈ 6,000~10,000 账号 token。**

### A.5 账号池抑制乱说话——诚实评估（不迎合大王）

| 层 | 抑制废话的机制 | 现状 / 池化后的变化 |
|---|---|---|
| 局内（第一道，真正的主力） | 单局 420~280 上限 + L0 +10 + **连击 base 翻倍** + LOSE_TOKEN 判定 | **早已存在，与池化无关**。话痨在局内 7~10 轮就会 LOSE_TOKEN 被抬走 |
| 跨局（第二道，池化新增） | 一局烂尾（尤其 LOSE_TOKEN）会**实耗冻结配额** → 池变小 → 下一局更难开 | 真实但**温和**：它惩罚的是"把一局打输/打废"，不是"一局内说话多" |

**诚实结论**：账号池确实新增了跨局代价（在 v0.1 的 3 局/日局数配额下，这个代价几乎等同、只是多了一层"烧钱"的体感），但**它不是治话痨的刀**——局内配额 + L0 连击翻倍才是。想再强一点，改的是局内罚则（如连击翻倍阈值 2→1、L0 后 3 轮降自信度），不是继续堆账号池。**不要把"账号池能抑制乱说话"当卖点宣传，把"每一轮都在真实烧钱"当体感传达就好（A.2 证明这个体感在轮次级是真的）。**

### A.6 隐性风险（主动说，不粉饰）

1. **重度付费玩家账号池巨大 → 单局内不再珍惜**：诚实说——P3 的珍惜由局内 420 保证，不因池大而消失；真正会松的是"跨局精打细算"，而这从来不是乐趣来源。可接受，但**禁止因此去卖"单局扩容"给重度玩家**（那才是自毁）。
2. **token 通胀 → 免费成本失控**：账号 token 总量必须设天花板（免费日发 + 广告日封顶 + 购买的累计），并保留全账户日局数上限（见 §F #26）——否则池化把"局是成本护栏"变成一个可被购买/刷取击穿的洞。
3. **双重付费困惑**：玩家又买 token 又买天数卡时，必须让"畅玩期内池静止不扣"完全可见（§C），否则会投诉"我花钱了还被扣"。

## §B. 免费发放量与开局门槛（账号池机制本体）

| 项 | 建议值 | 依据 |
|---|---|---|
| **单局典型消耗** | ≈300 token（L1 420 / L5 280，赢在 10~14 轮时常见 250~400） | 局级换算锚 A.4；**待 T1 校准** |
| **每日免费发放 N** | **900 token/日**（无结转、次日重置） | ≈3 典型局；全花成本 ≈0.135 元/日 ≈ **4 元/月/DAU**，精确对齐 v0.1/REL-001 C6 预算 |
| **开局门槛** | 账号池 ≥ **目标层配额全额**（L1 420…L5 280）时允许开局 | 冻结-返还（§A.3 A 案） |
| **冻结/返还** | 开局冻结 Q → 局内从冻结额扣 → 局终返还 Q−实耗 | 弃局按已发言实扣；无退款漏洞 |
| **日免费能撑几局** | 典型 3 局/日；若每局都打到 20 轮上限（单局≈400），900 只够 2 局+——**自限即成本护栏，属特性非缺陷** | 与 v0.1"3 直接发放"的可玩性一致（短局玩家体感 ~3 局） |

> 设计注：把"免费 3 局/日"从"局数配额"翻译成"900 token/日"，必然引入"省着说能多开几局、挥霍就早收工"的新自由度——这正是账号池想要的"说话在花钱"体感，代价是免费玩家的局数不再是个恒定整数。若上线后数据证明这个不确定性伤害留存（免费玩家抱怨"凭什么我今天只能打 2 局"），回退选项：直接按"每日 3 局免冻结额度 + 超出才吃账号池"的双池模型（见拍板点 #22 备注）。

## §C. 商品矩阵（token 充值 + 天数卡 + 订阅并存）

### C.1 双轨语义——谁在用钱买什么

| 轨 | 商品 | 买的是什么 | 机制 |
|---|---|---|---|
| **时间轨（限时畅玩）** | 天数卡 / 订阅 | 一段期限内"开局不冻结、不消耗账号 token"的畅玩权 | 生效期内：`new_session` 不冻结账号池，局内照旧（420 规则 + 全服日局数上限）；过期自动回落到 token 池计费 |
| **存量轨（永久资产）** | token 充值包 | 永久不过期的账号 token 存量，只在无畅玩权益时被局消耗 | 任何时候有效；畅玩期激活时**池静止不扣、UI 明示"畅玩中，余额暂不动"** |
| 免费层 | 日发 900 | 成本护栏内的基础游玩权 | 无结转，先于存量轨消耗（还是后于？见 C.3 规则） |

### C.2 最小商品矩阵（3 SKU 起步，建议先上 2 个）

| SKU | 定价区间 | 含 token | 典型局数（≈300/局） | 单局玩家成本 | 谁买 |
|---|---|---|---|---|---|
| **A. 天数卡** | 3 天 ¥6 / 7 天 ¥10（沿用 v0.2） | —（畅玩） | 期限内科次不限（受日局数上限） | 按局摊薄，越打越划算 | 爆发型：放假 / 卡关"今天想打穿"的人 |
| **B. 月订阅** | ¥15/月（年 ¥128） | —（畅玩 + 外观/内容权益） | 同上 | 同上 | 稳定型：每周都打、要外观/新内容 |
| **C. token 包** | **¥6 = 12,000 / ¥18 = 36,000 / ¥45 = 90,000** | 见左 | 40 / 120 / 300 局 | ≈0.15 元/局（毛利 ~70%） | 低频存钱罐：偶玩但不想订月卡、怕过期 |

**定价依据（1 元 = 2,000 token）**：token 成本锚 0.00015 元/token × 2,000 = 0.30 元成本 / 1 元收入 → **毛利 ~70%**，与 v0.1 订阅毛利同档；2,000 token ≈ 6~7 典型局，玩家单价 0.15 元/局 ≈ 月订阅重度打法的隐含单价，**不构成对订阅的碾压**（订阅还含外观与内容，token 包没有）。

### C.3 双重付费困惑的最小化规则

1. **重叠期不双扣**：畅玩权益激活时，token 池冻结不扣，界面显示"畅玩中 · 余额保留至 YYYY-MM-DD 后恢复计费"；
2. **消耗顺序**：畅玩期内打局不碰池；畅玩过期后先耗存量 token；存量与日发同池时，建议**日发 900 先行**（先烧免费、再烧买的，防止玩家"以为用的是买的、其实免费的先被清空"的错觉——这条建议先耗日发，保留付费 token 的"值钱感"）；
3. **一条铁律**：所有档位共享**全账户日局数上限**（建议 15 局/日，见 §F #26）——**账号 token 再大也不能击穿局次数上限**，这是防"重度玩家 token 池巨大烧穿算力"的硬闸（对齐 ENG-002 §3.1 单用户限流）。

## §D. 教练提示：第 3 次吃局内 token（大王第 3 点落地）

**现状与改动**：v0.2 §C 档 B（免费 2 次/局 + 局外广告囤"+3 次券"）——大王弃用广告链路做提示（不引广告 SDK、局内不打断）。新规则：**免费 2 次/局 + 第 3 次（封顶共 3 次/局）吃局内 token**。

| 项 | 建议值 / 结论 |
|---|---|
| 第 3 次吃多少局内 token | **20 token/次**（建议区间 10~30） |
| 换算依据 | 提示单次真实成本 ≈0.001 元（ENG-002 §1.2，529 token 输入）。按 1 token≈0.00015 元，真实成本平价 ≈7~10 token；**取 20（约 2~3× 真实成本，约合 0.003 元、占 L1 配额 ~5%）**——"肉疼但救得回"：吃掉的是本局 420 里的 20，不是不可恢复的真钱 |
| 吃的是谁的钱 | 局内 `token_remaining` −20 → 局终返还冻结额同步减 20 → 真实扣账号池 ≈0.003 元，同时覆盖厂商实际多花的 0.001 元提示调用 | 
| 对局内压迫感的影响 | **比广告优雅**：不打断、不引广告 SDK、不把"卡壳最痛时刻"变成变现点（v0.2 否决档 C 的理由），20 token 对 420 是一记轻量刺痛而非门槛 |
| 会不会有玩家为省 token 不敢用免费 2 次 | **不会**——免费 2 次不扣 token，心理无门槛；救急宽容（v0.1 必须免费 #7 的"基础 2 次免费"承诺保留） |
| 第 3 次后还想再要？封顶 3 次够吗 | **够，维持 3 次**。需要 >3 次提示说明不是"卡壳"是"读人能力不足"，再给就变成软肋查询器、侵蚀 P1（v0.2 §C 档 A 风险）；想要更多 → 重开一局（新局重新有 2 次免费），重开本身消耗账号池，形成自然节制。**订阅者/天数卡持有者也封顶 3 次**（统一，提示本就不是付费卖点；这微调了 v0.2"订阅者 5 次"的差异，见 §F #24） |

## §E. 广告换账号 token："无限看"裁定与封顶建议（大王第 4 点落地）

### E.1 "无限看"三宗罪裁定——全部成立，否决

| # | 罪状 | 裁定 | 依据 |
|---|---|---|---|
| 1 | 单人高频曝光 → eCPM 断崖 | **成立** | 主流激励视频 SDK 单设备日展示频控约 10~15 次，超限后平台风控 + 广告主预算不满，单人日曝光 >10~15 次后 eCPM 趋近 0（v0.2 B.3 已引用） |
| 2 | token 通胀 → 免费无限开局的漏洞 | **成立** | 无限看 = 无限免费局通道，直接击穿"局数是成本护栏"；免费 DAU 月成本从 ~4 元失控为无上限 |
| 3 | 刷量放大器 | **成立** | 脚本批量过激励视频 → 账号 token 无限膨胀 → 无限刷局 → LLM 账单爆炸（ENG-002 §3.1：100 脚本号 ≈10 万/月） |

**裁定：无限看否决**。随机奖励不能替代封顶——期望值再不稳，只要为正、可规模化，刷号 ROI 依然可预测地收敛为正。

### E.2 随机区间价值 + 封顶方案

随机区间（如 60~220 / 次）**确实有价值**：单账号单日累计获得不可预测 → 单脚本 ROI 方差大、批量养号调度成本高。但它只负责"让刷号不划算"，**不负责封成本**；封成本靠累计封顶。

**推荐方案（两闸）**：
- **主闸（成本闸）：单日累计获得 token 封顶 600/日**（≈2 典型局；对齐 v0.1/v0.2"免费体验 5 局/日 = 3 直发 + 2 广告局"的慷慨度，不缩水）；
- **辅闸（库存/eCPM 闸）：日观看软上限 15 次**（宽于 v0.2 的 8 次、仍压在平台风控线内）；
- 其他沿用 v0.2 B.3：观看完成走平台回调验签、≥90s 间隔、明示"观看后获得 token"、对局外点位（**此设计已不再有 v0.2 的提示券出口**，广告只换账号 token）。

### E.3 广告 token 期望值校准（1 次 eCPM 中值 0.04 元应换多少）

**目标公式**：token 对应成本 ≈ 广告收入 × 0.5~0.7（厂商不亏）。用 A.4 成本锚 0.00015 元/token：

```
单次广告可给 token ≈ (0.04 × 0.5~0.7) / 0.00015 ≈ 133~187
→ 取随机区间 80~220，期望 ≈150
校验：150 × 0.00015 ≈ 0.0225 ≈ 0.04 × 0.56 ∈ [0.5, 0.7]  ✓ 厂商毛利 ~44%
日封顶 600 token → 平均需 4 次观看达成 → 落在 15 次软上限内 ✓
```

> **（提醒大王的直觉校准）**：大王原提"20~80/次"期望 50，只覆盖 token 成本的 ~19%（50×0.00015/0.04），**会严重低估账号 token 的真实成本面**——若照 20~80 发，等于每看 1 个广告、厂商补贴 80% 以上的对局成本，无限看三宗罪会在"成本"这条上提前爆。故上调至期望 ~150。
> **渠道现实标注（非本设计域，只标注不展开）**：广告接入与收款依赖主体资质（见 REL-001 §4/§5：个人主体仅限工具类目虚拟支付、广告平台主体要求、收款需个体户/公司）。**个人阶段可先以打赏/赞助验证付费意愿，不把广告接入当作当前必做项**；本节数值是"若接入广告该按什么兑率"的设计答案。
