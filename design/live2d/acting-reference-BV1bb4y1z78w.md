# 角色表演主参考与第二版制作规格

日期：2026-09-09。用户指定的动作参考：[小声_s《逆转裁判高清素材合集》](https://www.bilibili.com/video/BV1bb4y1z78w/)。本次实际查看了 P1「成步堂动作展示」、P3「御剑动作展示」中的代表性姿态及说话变化，也查看了 P2 的审判长说话画面；没有逐帧核验全部 15 个分集。下列时间是观察到的近似位置，不是动作精确起止点。

本文件是后续角色动作制作的主参考。第一版真实 Live2D 工程和导出包保留；这里的第二版规格不代表新原画、绑定或动作已经完成。`source-v2` 是第一版制作过程中升级到 13 层的源包名称，与本文所称「第二版表演」不是同一版本概念。

## 第二版原画先改什么

用户随后提供截图并明确：异议使用**角色自身的左手**，右臂放低。画面朝右时，伸出的左臂应连接画面右侧肩部，胸前领带保持露出；不采用从画面左侧近肩跨过胸前的右臂。当前纠正稿为 `klein-point-left-01`，透明图与 PSD 在 `male-master/acting-v2/pose-sources-left-hand/`。旧 `klein-point-04` 的手侧错误，停止用于后续绑定。

保留黑紫短发、红制服、白衬衫、深蓝领带和金色细节。人物改为清楚的 3/4 朝向：玩家先按面对画面右侧的对手制作，身体、头部、视线和伸指方向一致。对局中具体摆放方向再与场景一起核验。

第一版模型的近正面构图、向镜头伸出的大手与参考不符。伸指原画需要重画整条动作臂及相应的肩胸姿态；不能只缩小现有手掌或旋转整张手臂图片。优先做三张相互一致的关键姿态：站立倾听、前倾质询、转肩伸指。三张通过构图和身份一致性检查后，再拆层、补遮挡和绑定。

试稿建议使用 1536×1536 源画布，保留接近第一版的人物像素高度，为横向伸臂增加空间。三姿态检查通过后统一锁定画布和头颈、肩肘腕锚点；不把这个建议尺寸写成现有 PSD 的实际尺寸。源画布与 2048 导出图集分别管理。

采用清楚的关键姿态、短促切入、姿态保持和局部形变。大幅转身、抱臂、托腮等透视和遮挡改变，允许使用专门绘制的姿态分支；不要求所有姿态之间长时间平滑插值。关节拆分服务于可见的动作，不能为了「有骨骼」把人物做成软管。

眼睑、眉、瞳孔、嘴角与肩颈共同表达情绪。冷静眨眼、尴尬闭眼笑、受打击挤眼分别设计。张嘴时保留口缘、牙齿或口腔的层次，避免整块黑洞。桌面动作仅用于已有桌面且接触点对齐的场景；无桌面的验收台使用前倾质询或抬手强调姿态。

### 本地原画管线的实际约束

只读核对发现，`tools/live2d/generate-male-master.py` 当前是第一版站姿生成器：画布固定 1024×1536，OpenPose 固定为双臂放低；身份引用旧 `male_char/tense.png`；负面词还排除了弯肘、侧面、愤怒和张嘴，不能原样用于新动作。图中虽然存在风格参考节点 10，但采样器连接节点 8，风格分支实际没有参与出图。`inpaint-male-layer.py` 是局部修稿工具，当前没有接身份适配或姿态控制。

旧工作流保留用于复现第一版。第二版需另建姿态工作图：以当前获选原创人物作为身份参考，分别提供站立、前倾、侧向伸指的姿态约束，核对采样器实际使用的身份与风格分支，并按动作清理相冲突的正负提示。局部修稿只在关键姿态已成立后使用。同一随机种子、相同提示或姿态线都不能保证像素对齐；必须实际检查三稿的身份、比例、朝向，再统一连接点后拆层。

## 动作库与游戏机制的对应

以下是依据参考为本项目设计的映射，不是视频作者给出的游戏机制分类。

| 动作 / 状态 | 身体与脸部表现 | 生命周期 | 顺序 |
|---|---|---|---|
| 冷静倾听 | 稳定站姿、注视对手、轻呼吸，闭口或轻说话 | 持续状态 | 第一批 |
| 紧张质询 | 胸口前倾、肩略抬、眉收紧、目光明确 | 进入 → 保持并可说话 → 退出 | 第一批 |
| 焦虑 | 肩颈收紧、眼睑压低、嘴角紧绷、小汗珠，呼吸加快 | 持续状态，可叠加质询 | 第一批 |
| 我有异议 | 转肩、整臂向对手伸指、强调口型 | 准备 → 快速伸指 → 保持陈述 → 退出 | 第一批 |
| 思考 | 托腮或视线下移，口型可独立变化 | 进入 → 保持 → 退出 | 第二批 |
| 受打击 / 绝望 | 短促退缩或前压反应，随后低头、塌肩、疲惫眼口 | 反应 → 低落保持 | 第二批 |
| 强调 | 短促压手或拍桌，身体同步发力 | 一次重音 → 返回当前质询姿态 | 第二批 |
| 自信反驳 | 手在腰侧、抱臂或摊掌，眼眉有变化 | 保持并可说话 | 第三批 |
| 尴尬 | 挠后脑、避开视线、勉强笑 | 反应或保持 | 第三批 |
| 出示 / 查看证据 | 持纸或证物，阅读后望向对手 | 道具保持与说话组合 | 第三批 |

原有压力阈值及状态顺序继续使用游戏机制的定义，不因美术动作调整数值规则。

## 绑定和运行时要求

1. 将身体姿态、说话口型、眨眼、情绪和外观选择分开管理。保持托腮、抱臂或伸指时可以说话；情绪会影响基础眼睛张开程度，眨眼在该基础上闭合和恢复。
2. 当前第一版异议 motion 会在 1.5 秒结束并回到默认。这是流程原型的行为。第二版使用「进入、保持、退出」阶段，由异议陈述结束或动作打断事件控制退出；不能在玩家仍陈述时强制收手。
3. 关键姿态切换要控制遮挡与手形，允许短切换。避免整条待机臂与伸指臂长时间同时半透明。需要运动的肩、肘、腕与袖口设共同锚点；透视差异明显的手形使用绘制分支。
4. 玩家与 NPC 共享动作含义、参数 ID 和方向约定。角色性格可通过姿态幅度、停顿和表情体现；动作不得改写当前选择的头发、脸和衣服。
5. 先制作三姿态、一套外观，再让第二套衣服通过同一伸指曲线和姿态切换。验证衣领、肩、袖和腕部接缝后，才批量增加外观与 NPC。
6. FREE 的参数与图层预算在拆层确定后核验。第一版模型为 13 个网格、28 个总参数、5 个有实际绑定的参数；第二版基础绑定现为 12 个网格、27 个默认参数、3 个有实际绑定的参数；规划中的参数不能计作已完成功能。详细结构审查见 `work/live2d/male-master/motion-architecture-review.md`。

## 验收与交付边界

- 隐藏状态文字，能从脸和身体区分冷静、紧张、焦虑、受打击。
- 单看伸指静帧，就能读懂角色指向谁；肩、肘、腕、指尖和视线方向连贯。
- 同一姿态的闭口与说话版本保持身体、道具和接触点稳定；眨眼不重置表情。
- 暂停、继续、连续异议和打断恢复行为正确，退出后回到当前状态而非固定默认。
- 第二套衣服复用同一动作时，肩袖不裂、遮挡正确，发型和面部选择不被动作覆盖。
- 最终同时交付可编辑源文件、真实 Cubism 导出包和浏览器中的动作验收；静态新稿不等于动画已完成。
