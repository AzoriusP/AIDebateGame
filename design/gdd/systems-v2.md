# 《抬杠模拟器》v2 系统设计

> 状态：已定稿（2026-09-04 大王拍板）｜前身：demo/（v1 玩法已验证成立）
> 本文是 v1 demo 之后的系统级设计，回答"怎么从能玩变成一套有深度的作品"。

---

## 0. 里程碑与定名

- 游戏正式定名 **《抬杠模拟器》**（原暂定《辩弈》）。
- v1 核心玩法（判定→自信度→token→动态漂移→双向异议→胜负）已成立。
- 设计总纲：**AI 原生的深度不靠内容堆量，靠"NPC 是活的且会记住你"**。

## 1. 复盘克制原则（设计禁令）

**一句话**：复盘只帮玩家提升"说话水平"，不替玩家做"决策"；只给战术反馈，绝不暴露数值攻略。

| 给（战术层） | 不给（攻略层） |
|---|---|
| 你太啰嗦，耗了大量 token | 他的「情感」值只有 2，去打情感 |
| 开头空泛，没切中要害 | 他的软肋是情感/认同 |
| 被他带偏话题了，忘了你在辩什么 | 你应该这样这样这样说（直接给话术） |
| 气势上被他压住了 | —— |

**理由**：雷达图已经把"该打哪"的信息给玩家了（软肋可见）。复盘再教一遍 = 二次喂攻略，玩家会变成"照数值打"而不是"临场读人"，杀死自由度底色。
**实现影响**：重写 `_retrospect` prompt —— 注入"只点评对话质量，禁止引用/推断维度数值，禁止给出'打哪维/怎么说'的具体指导"。

## 2. 双模式结构

### 2.1 天梯模式 = 系列赛（v2 主模式）
- 选选手（L1~L5）→ 与**同一个选手**连打 3 局 → **三局两胜**晋级/淘汰。
- **命题策略**：每局从该选手领域内抽**不同命题**（考验对"这个人"整体打法的适应，非单题记忆）。
- **NPC 跨局记忆**：第 2、3 局，NPC 记得你前几局的打法 → 开局"翻旧账"（"上局你老拿数据压我，这局我不吃这套"）+ 针对性微调。
- 悬念节奏：让一追二 / 被让二追一 都成立 → 系列赛的大比分 UI 和"赛点"气氛重要。

### 2.2 自由模式 = 沙盒
- 无晋级压力，纯切磋/实验。
- **记忆开关**：默认关；打开后 NPC 记住你 + 六维随交流微调（成长生效）。
- 用途：玩家自测手感、观察 NPC 成长、演示"AI 原生"。

## 3. NPC 记忆与成长系统（v2 核心）

### 3.1 记忆摘要
- 每局结束，LLM 生成 **≤45 字压缩摘要**（这玩家怎么打的：主攻维度/风格/金句/结果）。**v0.3 对齐实装**：原写「≤50 字」，实装 `_memory` 为 45 字，以实装为准。
- 只保留**最近 3 局**，防 prompt 膨胀。

### 3.2 六维微调（成长）
- 每局结束按"玩家有效命中的维度"统计 → 被打得多的维度**缓慢上调**（NPC 在长记性）。
- 钳制：单维累计漂移 **±2 封顶**（防成怪物/防被打崩）。
- 回弹：长时间冷落维度缓慢回落（成长有进有退，可恢复）。

### 3.3 本地存档（归属 = 玩家）
- 每 NPC 一份状态：`{ base_六维, 当前修正, 记忆摘要[3], 交手记录数 }`。
- demo 单机 = 一个本地文件 `npc_state.json`；**提供一键重置**（玩家随时清空重新养）。

### 3.4 记忆注入
- 开局 NPC prompt 注入记忆摘要 → NPC 自然"翻旧账"，玩家感知到"它记得我"。
- 修正值叠加到判定维度（与局内漂移分开：局内漂移=临时反应，记忆修正=长期成长）。

## 4. 动态人格生产流水线（工程化）

**运行时只微调，不生成。**"AI 生成"发生在配置阶段：
1. 用 LLM 批量生成 30~50 个 NPC 候选（六维/人设/口吻/领域），我做初筛；
2. 你审核挑选 + 改 → 进 **CSV 表格**（工程向：NPC/命题全部表格化，脱离手写 JSON）；
3. 运行时，NPC 的"动态感"全部来自记忆驱动的六维微调，稳定、省成本、可解释。

## 5. 技术影响清单（实现范围）

| 层 | 改动 |
|---|---|
| 数据 | `data/npc_state.json`（成长存档）；NPC/命题 CSV 化（工程向，可后置） |
| 后端 | session 增加"系列赛上下文"（局号/大比分/记忆注入）；记忆摘要生成（并入复盘调用）；六维微调结算；存档读写 |
| 复盘 | prompt 重写为克制版 |
| 前端 | 模式入口（天梯/自由）；系列赛 UI（第几局、大比分、赛点）；记忆/成长指示（如"TA 记得你上局……"） |
| 配置 | NPC 生产流水线（批量生成脚本） |

## 6. 落地顺序建议

```
P0-1 复盘克制版（最小改动，立刻做）
P0-2 本地存档 + 记忆摘要 + 六维微调（NPC 成长底座）
P1-1 天梯系列赛（3 局 2 胜 + 记忆注入 + 系列赛 UI）
P1-2 自由模式 + 记忆开关
P2-1 NPC/命题 CSV 化 + 批量生成流水线
P2-2 美术演出补全
```
