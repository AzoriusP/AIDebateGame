## 1. 一句话定位（Elevator Pitch）

> **《抬杠模拟器》是一款 AI 原生的中文辩论游戏：你说人话，AI 裁判把它翻译成可量化的打击；你用一份有限的说话预算，把一个会漂移、会反驳、会记住你的 AI 对手，把 TA 的自信度从满格说到归零。**

30 秒补充版（给评委/路演用）：

- **你输入的是自由文本，不是对话选项**——玩家每一句都是自己组织的一句话论点。
- **对手是活的**——TA 的六维人格会在对辩中漂移，被打疼的维度会上浮警觉，被冷落的维度会下沉露出新破绽；跨局还会记住你的打法并翻旧账。
- **每一句话都是资源**——说话要花 token，废话与打错方向各有各的代价，逼你想清楚再说。
- **AI 是裁判，不是神谕**——判定走结构化 harness（维度白名单 + 强度分档 + 状态层确定性持有），可解释、可复现、抗注入，玩家能归因、能学习。

## 2. 游戏是什么

### 2.1 品类与形态

| 维度 | 定案 |
|---|---|
| 品类 | **AI 原生 · 说服博弈（Persuasion Duel）** —— 单人对抗、短局、有量化胜负的辩论/说服模拟。不是 RPG、不是叙事冒险、不是聊天玩具。可对外表述为"辩论擂台 + 轻天梯"。 |
| 平台 | **Web（浏览器，桌面优先）**。零安装、可发链接、评委点开即玩——这是参赛形态的最优解。 |
| 技术形态 | 本地 LLM（Ollama）+ 云端 API 双通道，可降级到 Mock 规则模式（无模型也能演示）。 |
| 单局形态 | **1 v 1，一题一对手一份预算**，单局数分钟。 |
| 赛事单元 | **系列赛三局两胜**（同一对手连打三局、每局换题）。 |
| 体量 | 5 层天梯，逐层解锁；当前实装每层 1 名对手，目标每层 3 名。 |

### 2.2 玩家在做什么（动词优先）

玩家的核心动词只有六个，它们构成体验的全部骨架：

| 动词 | 玩家实际在做的事 | 设计意图 |
|---|---|---|
| **读** | 读六维雷达图、对手的表情与措辞，判断"TA 现在最怕什么" | 情报即乐趣；可读才可学 |
| **说** | 用**一句话**组织一个论点（打字或语音），不是点选项 | 生成 ≠ 选择，这是本作与传统对话游戏的根本分野 |
| **赌** | 这句话要花掉说话预算，押它命中软肋 | 资源约束 → 决策重量 |
| **看** | 看判定标签（命中哪一维、什么强度）、自信度、剩余预算、对手漂移与表情 | 每次结算都要能归因，反"判定玄学" |
| **换** | 软肋被反复打会上浮失效，必须换维度、换打法 | 反抄作业，持续读人 |
| **扛** | 对手跌到背水一战线后会加压、主动打异议甩难论点，你要顶住 | 对手是活的，胜利要有代价 |

> **一句话总结玩家体验**：*在预算的倒计时压迫下，读懂一个会反抗的活人，然后精准地、一句一句地把 TA 说崩。*

## 3. 目标用户与需求

### 3.1 用户画像

| # | 画像 | 特征 | 被什么吸引 | 优先级 |
|---|---|---|---|---|
| A | **「杠精型表达者」**（主力） | 18–35 岁，中文互联网重度用户，爱看辩论/播客/长帖/脱口秀，评论区有表达欲，现实里总觉得"我当时该那么说" | 终于有一个地方，说赢人是有分数、有反馈、有天梯的 | **P0** |
| B | **「想练嘴皮子的人」**（次主力） | 面试/销售/法务/教师/产品经理等靠表达吃饭的人，把游戏当"有对抗压力的说话训练" | 即时、可归因的表达反馈；复盘讲"你哪里说得不好" | P1 |
| C | **「AI 玩法观察者」**（传播放大器） | 赛事评委、独立开发者、游戏媒体、AI 产品人 | 想看"AI 原生"到底能怎么玩，而不是又一个套壳聊天 | P1（传播价值，不为其牺牲 A/B 体验） |

### 3.2 核心情绪需求（玩家为什么留下）

1. **"我说话是有用的。"** —— 现实中的争论大多无效、无反馈、无胜负；本作里每一句话都量化生效，命中软肋时对手会真的动摇。**即时且可归因的正反馈 = 胜任感**。
2. **"我赢了一个嘴硬的人。"** —— NPC 有立场铁律（嘴硬、找补、绝不轻易认输），所以赢下来是有重量的征服感，不是推倒沙袋。
3. **"我变强了，而且是我自己看出来的。"** —— 从"乱说"到"会读人"的进步由玩家自己发现；因此**复盘必须克制**（只评表达，不喂数值攻略），把成长的解释权留给玩家。

### 3.3 心理学映射（简述，用于校验设计取舍）

- **Bartle 玩家类型**：主力 **Achiever**（通关天梯、逐层解锁、集齐对手）+ **Killer**（"把人说崩"的 PvE 化征服）；**Explorer** 由自由切磋模式承接（试打法、观察 NPC 成长）。社交型需求不靠多人联机满足，而靠**拟社会关系**——NPC 记得你、翻旧账、越打越懂你。
- **自我决定论（SDT）**：
  - *胜任感* ← 可归因的判定标签 + 会变化的对手（难度来自"要一直读对"，不是来自数值墙）；
  - *自主性* ← 自由文本输入，怎么说都行，没有唯一正确选项；
  - *联结感* ← 跨局记忆与人格成长，让对手成为"一个人"而不是"一个关卡"。

> **校验结论**：任何新增设计，若削弱"可归因"、削弱"怎么说都行"、或把对手降格成固定数值关卡，即视为违背本作心理根基，应否决。

## 4. Fun Hypothesis 与 Design Pillars

### 4.1 Fun Hypothesis

> **在 token 预算的倒计时压迫下，玩家通过「读懂」NPC 会漂移的六维人格，精准命中其动态变化的薄弱点，体验「逐步攻破一个会反抗的活人」的智力博弈快感。**

拆解：核心爽点 = **洞察（读人）+ 精准打击（打弱点）+ 对手会反抗（活的）**。不是"背标准答案"，而是"和一个人较劲"。

### 4.2 Design Pillars（4 条，大王已拍板，措辞保留）

1. **「先读懂，再出拳」（Read, then strike）** — 情报可视、可学习：六维图 + 漂移信号 + 每次加/扣分的**维度标签反馈**，让玩家能建立"什么话对谁有效"的心智模型。**反判定玄学**。
2. **「对手是活的」（A living opponent）** — NPC 会警觉、会切换论点、会反驳、会加固强项，绝不被动挨打。**反抄作业**。
3. **「每一句话都是资源」（Every word costs）** — token 是战略资源，废话与打错方向都有明确代价，逼玩家精炼表达。**反刷屏试探**。
4. **「AI 是裁判，不是神谕」（AI as referee, not oracle）** — 结构化 harness 让判定**可解释、可复现、抗注入**，玩家信任分数。**这是「AI 原生」的技术正当性来源**，也是路演要讲的核心。

> **支柱漂移红线**：任何改动若让"读人"变成"背表"、让"活的对手"变成"固定关卡"、让 token 变成"一个无关痛痒的计数器"、让判定变成"看 AI 心情"，即构成支柱漂移，必须回滚或重新拍板。

## 5. 核心循环（骨架级）

**一段说明**：开局系统抽一名对手 + 一道与 TA 人设匹配的命题，按人设分配双方立场（玩家自动站对面），发给玩家一份说话预算和一张带误差的六维雷达图。此后每回合：玩家说一句话 → harness 把它映射成"维度 × 强度"的结构化判定 → 确定性结算同时驱动三个变量（**自信度**下降/上升、**token** 扣减、NPC **六维漂移**）→ 调度器决定本回合演出节拍（NPC 动摇 / 反驳 / 主动异议 / 抛钩子）→ 前端先播演出，NPC 台词流式跟上。玩家看着三个变量与对手的表情变化，修正对"这个人"的判断，再说下一句。自信度归零 = 玩家胜；预算耗尽 / 超时 / 超回合 = 玩家败。

```
┌──────────────────────── 单局核心循环（骨架，不含数值）────────────────────────┐

  [开局]  抽对手 × 抽命题（人设域匹配） → 按人设分派立场 → 发预算 + 六维图（带误差）
     │
     ▼
  ┌────────────┐
  │  读：读图   │ ◄──────────────────────────────────────────┐
  │  读表情/措辞│                                             │
  └─────┬──────┘                                             │
        ▼                                                    │
  ┌────────────┐                                             │
  │  说：一句话 │ 自由文本（打字 / 语音）                      │
  │  赌：押软肋 │                                             │
  └─────┬──────┘                                             │
        ▼                                                    │
  ┌──────────────────────────────────────┐                    │
  │  harness 结构化判定（LLM 只做映射）   │                    │
  │  维度白名单 → 强度分档 → 方向校验     │                    │
  └─────┬────────────────────────────────┘                    │
        ▼                                                    │
  ┌──────────────────────────────────────┐                    │
  │  确定性结算（纯函数，LLM 无权写状态） │                    │
  │  ① 自信度 ±   ② token −   ③ 六维漂移  │                    │
  └─────┬────────────────────────────────┘                    │
        ▼                                                    │
  ┌──────────────────────────────────────┐                    │
  │  调度节拍 + 演出（前端先播，台词后到）│                    │
  │  NPC 动摇 / 反驳 / 主动异议 / 抛钩子  │                    │
  └─────┬────────────────────────────────┘                    │
        ▼                                                    │
    看 → 换（软肋上浮失效，换维度）─────────────────────────────┘
        │
        ├── 自信度归零 ──► [胜] ──► 克制版复盘 ──► 系列赛计分 / 解锁下一层
        └── 预算耗尽 / 超时 / 超回合 ──► [败] ──► 克制版复盘 ──► 重打
```

**循环的三个设计要点（总纲级约束，任何系统 GDD 不得违背）**：

1. **玩家能看见三个变量的变化，才能学习**——自信度、token、六维漂移缺一不可视化。
2. **结算必须是确定性的**——LLM 只产出"判定信号"与"台词"，状态迁移只走游戏代码。
3. **一次输入只解决一个论点**——判定只计最高一维，防止"一石多鸟"刷分。

## 6. 差异化与竞争定位

### 6.1 定位空档

```
                    输入自由度（玩家能说什么）
                    低（选选项）          高（自由文本）
                ┌─────────────────────┬─────────────────────┐
   强（有胜负/  │  传统叙事/辩论游戏    │  ★《抬杠模拟器》     │
   可量化/可学）│  逆转裁判·极乐迪斯科  │  自由输入 + 强框架   │
                ├─────────────────────┼─────────────────────┤
   弱（无胜负/  │  视觉小说/选项剧情    │  AI 陪聊·AI Dungeon │
   不可量化）   │                      │  自由但无博弈        │
                └─────────────────────┴─────────────────────┘
                        框架强度（规则/可学习/可赢）
```

**一句话定位**：本作站在 **"AI 聊天玩具"（自由但无博弈）与"传统叙事游戏"（有框架但输入被锁死）之间的空档**——上半身用 LLM 拿到"开放输入的活体对手"，下半身用传统游戏设计拿到"可量化的强框架"。这个空档此前之所以是空的，正是因为**没有 LLM 就做不出"对任意一句话都能给出合理判定的裁判"**。

### 6.2 AI 原生的正当性（去掉 AI，这个游戏为什么就不成立）

这是参赛路演的核心论证。**三个不可替代性，缺一游戏不成立**：

| # | AI 承担的不可替代角色 | 若去掉 AI（换成预写脚本 / 规则引擎）会退化成什么 | 对应支柱 |
|---|---|---|---|
| 1 | **可解释的裁判**：把任意一句自然语言论点，映射为"维度 × 强度"的结构化判定 | 规则引擎无法覆盖开放输入的语义空间 → 只能退回"关键词匹配"或"预设对话选项"，本作立刻退化成几十年前的选项式辩论游戏 | P4（AI 是裁判） |
| 2 | **活体对手**：实时生成反击台词、被说服的动摇过程、跨局记忆与翻旧账 | 预写台词树无法覆盖玩家千变万化的打法 → 对手必然变成"复读机 + 沙袋"，支柱 2「对手是活的」直接崩塌 | P2（对手是活的） |
| 3 | **人格的动态性与成长**：局内六维漂移的呈现、跨局记忆摘要、复盘与教练提示 | 这些都是运行时生成的内容，静态配置无法表达"这个 NPC 因为和你打过三局而变了" | P2 + 联结感 |

**反向论证（一句话）**：如果只把 AI 拿来做"更聪明的分支对话"，那它只是省了文案工；本作是**把 LLM 同时用作"裁判"与"对手"两个结构性角色**——去掉任一个，核心循环就断。

### 6.3 与近似品的差异

| 近似品 | 它是什么 | 我们的差异 | 差异的性质 |
|---|---|---|---|
| 《逆转裁判》类（法庭辩论） | 找矛盾、出示证物，本质是**解谜**，答案是唯一的 | 我们没有唯一解，判定的是"这句话的说服力"，同一题有无数种赢法 | **从解谜 → 博弈** |
| 《极乐迪斯科》类（对话检定） | 自由对话 + 掷骰检定 | 我们不掷骰，玩家的措辞质量直接决定结果；"说得好"是技能不是运气 | **从随机 → 可归因的技巧** |
| AI 陪聊 / 角色扮演（Character.AI 类） | 活的对话对象，但无规则、无胜负、无成长 | 我们给它装上"六维雷达 + 自信度条 + 预算倒计时 + 结构化判定"的强框架 | **从陪伴 → 可赢的博弈** |
| AI Dungeon 类（AI 生成冒险） | 极高自由度，但挑战稀薄、无量化 | 我们有明确的输赢、天梯与解锁，自由度服务于博弈而非代替博弈 | **从漫游 → 有目标的对抗** |
| 辩论/演讲训练工具 | 训练向，严肃、无娱乐演出 | 我们是游戏：有立绘表情、异议闪帧、语音、天梯仪式感 | **从工具 → 有演出的游戏** |

**结论**：本作不可被归类到以上任何一格，这是好事，也是需要在路演中主动讲清的——**"AI 原生"不是标语，而是"这个玩法在 LLM 之前根本无法实现"的事实陈述**。

## 7. 范围边界（solo 开发的生命线）

### 7.1 本作做什么（In Scope）

| 域 | 范围 |
|---|---|
| 玩法 | 1v1 文字辩论；读图 → 出拳 → 判定 → 三变量结算 → 对手回应 的完整闭环 |
| 模式 | 天梯系列赛（三局两胜，逐层解锁）+ 自由切磋（记忆开关） |
| 内容 | **5 层对手 · 定案共 5 名（每层 1）**（2026-09-07 裁决：内容量让位于演出打磨与数值平衡，不追 15 名）；命题库 50 题（分层、分主题域、有敏感过滤） |
| 元系统 | NPC 跨局记忆（翻旧账）+ 六维成长微调 + 本地存档与一键重置 |
| 表现 | 六维雷达图、自信度条、预算/倒计时 HUD、双向异议闪帧、分层表情立绘、打字机 + TTS 语音、系列赛晋级/淘汰仪式 |
| 技术 | Judge/NPC 双 LLM 分离、状态层确定性持有、反注入护栏、本地/云端/Mock 三模式 |
| 语言/平台 | 简体中文；Web 桌面优先；无安装、可发链接 |

### 7.2 本作明确不做什么（Out of Scope，含设计禁令）

> 这些不是"以后再说"，而是**本作不做**。写在这里是为了防止范围 creep 拖垮 solo 开发。

| # | 不做 | 理由 |
|---|---|---|
| 1 | **多人联机 / PvP / 排行榜服务器** | 运营与成本黑洞，与赛事提交无关 |
| 2 | **3D、大世界、场景探索** | 本作的乐趣在对话与判定，不在空间 |
| 3 | **主线剧情 / 战役叙事 / 世界观百科** | 世界观只做"点到为止"的对峙擂台框架，够用即可 |
| 4 | **玩家捏脸 / 换装** | 降为 P3 愿景；玩家形象做"1 套立绘 + 4 档表情"即可 |
| 5 | **判定"玩家被说服"** | **设计禁令**：LLM 永不判定真人被说服。玩家失败只来自资源耗尽（预算/时间/回合）与主动认输 |
| 6 | **喂数值攻略的复盘** | **设计禁令（复盘克制原则）**：复盘只评表达质量，不给"打哪一维/怎么说"；雷达图已经给了"该打哪"，复盘再教一遍会杀死自由度底色 |
| 7 | **开放式话题输入** | 命题必须来自受控题库（分层 + 主题域 + 敏感过滤），否则内容安全不可控 |
| 8 | **玩家侧数值养成线（等级/装备/卡牌构筑/抽卡）** | 成长感只能来自"玩家自己变会读了"与"NPC 记得你"，不能来自数值膨胀 |
| 9 | **移动端原生 App / 付费内购 / 账号系统** | 与"可发链接、评委点开即玩"的核心诉求无关 |
| 10 | **运行时 AI 生成 NPC** | 人格生成只在**配置阶段**用流水线批量产出 + 人工审核；运行时只做确定性微调，保证稳定、省成本、可解释 |

## 8. 成功标准：什么算做成了

### 8.1 玩家行为指标（可观测、可自测）

| # | 指标 | 判定"成了"的样子 | 数据来源 |
|---|---|---|---|
| 1 | **学习曲线可见** | 同一玩家前 3 局的"有效命中率"显著低于第 4 局之后——证明六维图 + 判定标签真的教会了玩家读人 | 后端命中日志 |
| 2 | **单局时长落在目标区间** | 中位数稳定在"数分钟"量级，不出现大量超时局或秒败局 | 会话日志 |
| 3 | **主动再来一局率** | 败局后有相当比例玩家立刻重打（说明"差一点"而非"不想玩"） | 前端埋点 |
| 4 | **换对手/换模式重玩** | 通关后有玩家继续打其他对手或进自由模式（说明内容有复用价值） | 进度存档 |
| 5 | **不用攻略也能赢** | 冷启动玩家（不看任何说明）能在合理尝试次数内通关 L1 | 试玩观察 |
| 6 | **反例红线** | 若玩家普遍采用"固定一套话术打到底"，说明漂移失效，本作失败 | 命中维度分布统计 |

### 8.2 赛事评审维度（对齐 AI 原生子赛道）

| 评审维度 | 我们的回答 | 证据 |
|---|---|---|
| **AI 原生的正当性** | 去掉 AI，裁判与活体对手双双不成立（§6.2） | 总纲 §6 + 路演 Demo 对比（关掉 LLM 用 Mock 模式演示退化） |
| **完成度（是真游戏，不是 demo 壳）** | 完整闭环：模式 → 匹配 → 对辩 → 胜负 → 复盘 → 解锁；有存档、有成长、有仪式感 | 可玩链接 + 录屏 |
| **游戏性 / 可学习性** | 六维 + 强度档 + 漂移，构成"可归因、可精进"的技巧空间，不是随机演出 | 试玩数据 + 命中分布 |
| **演出与表现力** | 异议闪帧、分层表情、TTS 语音、系列赛晋级仪式——裸聊天框拿不了奖 | 美术圣经 + 实机 |
| **工程可信度** | 结构化 harness：裁判/NPC 分离、状态层确定性持有、反注入、可复现 | 架构文档 5 条 ADR + 校准集 |
| **创意与差异化** | "开放输入的活体对手 × 可量化强框架"的空档定位（§6.1） | 总纲 §6 |

### 8.3 个人目标（solo 可持续性）

1. **有一条能对外直接发的链接 + 一段 90 秒录屏**，陌生人 30 秒内看懂怎么玩。
2. **内容量达标**：每层对手数量达成目标值，命题库覆盖各层主题域。
3. **文档与代码可交接**：总纲 + 系统索引 + 分系统 GDD 齐备，任何人接手能看懂设计意图（这正是本次文档结构化的目的）。
4. **solo 可维护**：不引入任何"只有作者本人会修"的技术债。

## 附录 B · 术语与口径统一（总纲级约定）

| 术语 | 统一口径 |
|---|---|
| **自信度**（confidence） | NPC 专有属性，**100 → 0**，0 = 被说服 = 玩家胜。历史文档中的"认同度"为同一变量的方向反转旧称 |
| **六维** | 逻辑力 / 证据力 / 情感力 / 利益力 / 认同力 / 权威力（LOGIC / EVIDENCE / EMOTION / UTILITY / IDENTITY / AUTHORITY） |
| **软肋 / 强项** | 六维中的低值维 / 高值维，判定基于**漂移后的当前实际值**，不基于初始值 |
| **token** | 说话预算（游戏内资源单位，非 LLM token），消耗 = 固定底扣 + 超长字数 |
| **漂移** | 局内临时的人格变化（被打上浮 / 冷落下沉 / 强项加固） |
| **成长** | 跨局的长期变化（记忆摘要 + 六维微调，持久化到本地存档，可一键重置） |
| **P0 / P1 / P2** | 系统优先级：MVP 必需 / 差异化增强 / 愿景 |
