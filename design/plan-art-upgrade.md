# 美术升级执行计划

> 2026-09-09：本文的角色动画技术选型与先后次序已被 [Live2D 母模制作方案](live2d-character-production.md) 替代；伸指动作和三槽换装是首套母模验收要求。其余历史内容保留供对照。

**目标**：UI 全面升级为逆转裁判风 + 2D 角色捏人（P1+P2），P3 Spine/DragonBones 留作升级选配。
**状态**：已评估/已拍板/开工中（2026-09-06）

---

## 决策摘要

| 决策点 | 拍板 |
|---|---|
| 节奏 | **P1+P2 先做，P3 后议** |
| 资产路线 | 扩到 **15 NPC（5层×3）** |
| P3 约束（备忘） | ① Web 效率最高 ② 动画简单（头/眼/手晃动） ③ 未来支持"照片 AI 化转角色" ④ 游戏通用骨骼动画格式 |

## P1 · UI 逆转裁判化（**本周**）

- 配色：三色铁三角（深邃靛蓝 / 异议红 / 认同金）沿用 `art-bible` 色板
- 字体：思源宋体 Heavy（粗体 fallback：Songti SC / SimSun / 黑体），保证无网络依赖
- 质感：诉讼/票据/印章/划线纹理（CSS/SVG）
- 对话布局：玩家左、NPC 右、左右气泡对称（按用户草图）
- 演出强化：异议闪屏 + 大字弹出 + 屏幕震动 + shake 已部分实现，CSS 升级
- 角色档案卡：右键 NPC 浮卡（雷达图 + 性格/工作/家庭 标签）
- 任务拆解：
  - [ ] HTML 框架重做（按草图布局）
  - [ ] CSS 重制（色板/字体/质感/动画）
  - [ ] 异议演出 CSS 强化
  - [ ] 字体栈 + 票据纹理 SVG
- 验收：全站视觉风格统一为"法庭对峙"，不依赖网络字体

## P2 · 分层 PNG 资产 + 捏人 UI（**后续**）

- 资产：15 NPC × 半身立绘 × 4 表情（得意/从容/动摇/被说服）+ 玩家 1 套 × 4 表情
- 分层：头 / 脸 / 身体 / 衣（attachment 切换 = 捏人）
- 管线：ImageGen 批量（已有经验 `tools/gen_npcs.py`），描述词锁定角色一致性
- 捏人 UI：玩家自定义选择器（4 头 + 4 衣 + 4 表情切换）
- 验收：能换头/换脸/换衣，能切换 NPC 表情立绘

## P3 · 骨骼动画（**P2 完成后议**）

- 引擎候选：Spine（WebGL 加速、生态最广、付费 $69/项目） / DragonBones（免费、国内主流、Canvas）
- 动画列表：空闲/说话/破防/被说服 等基础动作（头、眼、手晃动）
- 决策因素：等 P2 完成后根据演出需求定

## 不在范围内

- 照片 AI 化转角色（用户愿景，纳入待办，需 P3 骨骼定型后实现）
