## 2. A8 专项定义：两条通道必须分开

这是唯一一条无法靠"抄实装数值"解决的冲突——它不是数值问题，是**概念分层**问题。定案如下：

| 通道 | 名称 | 作用域 | 生命周期 | 钳制 | 驱动系数 | 存储 |
|---|---|---|---|---|---|---|
| 通道 1 | **局内漂移**（drift） | 单局内六维的临时变化 | 局末清零，不跨局 | 单维 **±3.0**（`DRIFT_CLAMP`） | `DRIFT_VIGILANCE 0.5` / `DRIFT_ABANDON 1.0` / `DRIFT_FORTIFY 0.5`，**× 该 NPC 的个性乘数** | 会话内存 |
| 通道 2 | **跨局成长**（growth） | NPC 因与你交手而产生的长期变化 | **持久化**，可一键重置 | 单维累计 **±2** 封顶，冷落缓慢回弹 | 局终按有效命中维度统计微调 | `data/npc_state.json` |

**为什么必须分开写**：两份旧文档都只写"钳制"，未标层级，导致 ±2 与 ±3 极易混淆。玩家感知上二者也完全不同——漂移是"这一局 TA 在变"，成长是"TA 记得你、变难了"。

> 落地要求：写 `systems/05-drift-system.md` 时，A8 必须作为独立小节，且明确标注本系统**只负责通道 1**，通道 2 归 `21-npc-memory-growth.md`。

## 3. 实装真值基线（本次核实的全部数值）

> 来源：`demo/server.py` 常量区与 `demo/data/npcs.json`。**后续任何文档引用数值，以此为准。**

### 3.1 自信度与 token

```
CONFIDENCE_DELTA = {
    "weak":   {"L3": -40, "L2": -20, "L1": -8},    # 命中软肋 → 自信度下降
    "normal": {"L3": -18, "L2": -9,  "L1": -3},
    "strong": {"L3": +8,  "L2": +4,  "L1": 0},     # 命中强项 → 被反驳，自信度回升
    "L0": 0,
}
TOKEN_BASE = 20          # 每条消息固定底扣
TOKEN_FREE = 60          # 免费字数
TOKEN_PER_CHAR = 1
TOKEN_L0_PENALTY = 10    # 废话题额外惩罚
TOKEN_L0_STREAK_DOUBLE = 2   # 连续 2 条 L0 → 第 2 条起底扣翻倍
```

### 3.2 漂移与节奏

```
DRIFT_VIGILANCE = 0.5    # 警觉上浮 × npc.drift_personality.vigilance_mult
DRIFT_ABANDON   = 1.0    # 弃守下沉 × npc.drift_personality.abandon_mult
DRIFT_FORTIFY   = 0.5    # 强项加固（无个性乘数）
DRIFT_CLAMP     = 3.0    # 局内漂移钳制
MAX_TURN = 20            # 回合上限
TIME_LIMIT_S = 480       # 单局 8 分钟
objection_threshold(tier) = 50 + (tier - 3) * 5    # L1=40 … L5=60
objection_intensity(below) = clamp(1 + below // 15, 1, 3)
```

### 3.3 软肋 / 强项判定

```
_direction(state, dim):   # 基于漂移后的当前实际值
    val <= 4.0  → 软肋（weak）
    val >= 6.5  → 强项（strong）
    其余        → 普通（normal）
```

## 5. 裁决后的连带影响

1. **A1/A2 牵动面最大**：自信度口径此前只改了抬头没改正文，导致任何读 core-loop 的人都会算反方向。现已全文修正。
2. **A5 的「基于漂移后实际值」是设计核心，不是实现细节**。它决定了"软肋会被打没、冷落维会变成新软肋"，是支柱 2「对手是活的」的量化根基。写漂移 GDD 时必须显式写出，不可省略。
3. **A6 个性乘数此前完全无文档**——它是不折不扣的差异化设计（陆教授警觉 1.4、赵律师难弃守 0.8），却只存在于代码与数据里。solo 项目这种"只在代码里的设计"是最危险的隐性知识。
4. **A12 定案 5 名**意味着：赛事评审若问"内容量"，回答口径应为「5 个精调对手 + 50 命题 + 三局两胜系列赛」，而非拼对手数量。总纲 §7.1 范围边界已按此写。
